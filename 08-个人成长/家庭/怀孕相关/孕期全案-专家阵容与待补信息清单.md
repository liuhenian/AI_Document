## 1.2 二、我目前已经看到的关键风险点（等你的信息来确认）

1. **社保/生育险断档**：她目前在求职。福州生育保险待遇通常要求**用人单位连续缴费满一定月数、且分娩时处于参保状态**。若这几个月断缴，产检报销与生育津贴可能受影响 → 需要尽快确认走哪条路（尽快入职 / 灵活就业参保 / 居民医保兜底 / 你的医保能否共用）。
2. **白天独处 + 你中午回不了家**：孕早期有孕吐与突发不适风险，医院 30 分钟路程、父母都不在福州 → 必须建立"应急联系人 + 一键呼叫 + 就近医院"机制。
3. **甲减 × 福建沿海饮食**：福州海鲜、海带紫菜汤、鱼丸虾皮都常见，**碘摄入偏高的概率很大**，与她"控碘"的要求直接冲突 → 需要把日常饮食里的碘算一笔账。
4. **福建是地中海贫血高发区**：建议确认是否做过血常规 + 血红蛋白电泳/地贫基因筛查（孕前没做的话，孕早期补做）。
5. **失业 + 怀孕的心理叠加**：这是本次孕期最需要主动干预的一条心理线（自我价值感 + 经济压力 + 身体变化三重叠加）。
6. **异地父母 + 产后照护真空**：双方父母都不在身边，月子怎么安排必须**产前 3 个月定下来**，不能到时候临时协调。
7. **孕 5 周还太早**：现在最要紧的是确认**宫内孕 + 胎心**（一般 6–7 周可见），以及建档排期。
8. **产检医院排期**：福州热门妇产医院建档名额紧张，孕 6–8 周要尽快落定。
