## 一、★ 四条时间原则

### 1. 一周只拍一次，不是天天拍

**单期 = 一道菜 = 一次拍摄。** 其余工作日晚饭正常做、正常吃，**手机不参与**。

### 2. 工作日你的厨房成本是 50 分钟，不是 105 分钟

| 环节 | 谁做 |
|---|---|
| 买菜 | **提前买好**，不占下班时间 |
| 备菜（洗 / 切 / 配 / 腌） | **老婆做** —— ★ 要拍备菜画面时另加 **15min** |
| **炒制** | **你做** ← 拍摄就在这一段 |
| **收拾** | **你做** |

> ⚠️ 但这个前提**只在常态成立**。国庆那类"独自一人"的时期，买菜 / 备菜 / 炒 / 收拾全是你 → 基线回到 105 分钟。

### 3. 工作日晚上不排剪辑

做饭那天的晚上是这样的：

```
18:40 到家
18:40–18:50  上镜清洁 10min          ← ★ 排在拍摄之前
18:50–19:15  炒制 25min（动作片段录制）
19:15–19:30  成品热镜 15min          ← A位起锅装盘 → 挪B位拍成品/夹一筷/封面
19:30–19:55  吃饭
19:55–20:20  收拾
20:20 之后   家人 / 休息        ⛔ 不排剪辑、不排学习
```

> ⚠️ **若当期要拍备菜画面** → 另加 15min，整条链后移到 20:35。
> ⚠️ **成品镜必须在出锅 ≤5 分钟内拍完** —— 绿叶转黄、勾芡返稀、蒸汽归零都会让剪辑跳色。

→ **选题 / 脚本 / 评论回复 / 手机粗筛** 全部搬到 **通勤 + 午休**（约 30min/天）。

### 4. 只有一个机位布置，只做一道主拍菜

机位布置一次（B 备菜 → A 炒 → B 成品 = 搬机 2 次）。
⛔ **不要为了"攒素材"在同一晚多做第 2 道主拍菜** —— 搬机会变成 4 次，而且第一道菜会等凉。
> 攒素材靠"**同一道菜多录 1~2 个动作片段**"，不靠"多做一道菜"。
> ⚠️ **副菜 1 道可以做、但不拍** —— 放在**炒制等待期**做（那 3~8 分钟手机本来就停机），**不增加一次搬机**。

## 二、周结构（硬边界）

```
工作日（周一~周五）
  ├ 通勤 + 午休  约 30min/天 → 选题 / 脚本 / 评论回复 / 手机粗筛
  ├ 18:40 到家（老婆已备好菜）
  ├ ★ 拍摄日只选 1 天（建议周四）：上镜清洁 → 炒制+片段录制 → 成品热镜 → 吃 → 收拾
  ├ 非拍摄日：炒菜 → 吃 → 收拾（约 75min）
  └ 20:20 之后  → 家人 / 休息        ⛔ 不排剪辑

周五
  └ ★ 多做一个菜 → 作为周六 / 周日的午餐（保证周末剪辑块不被切）

周六
  ├ 08:00–10:00  ★ 剪辑块 A（粗剪 + 掐时长）
  ├ 10:00–11:00  缓冲（补拍 / 传输 / 什么都不做）
  ├ 11:00–12:00  做饭（老婆备菜 → 他炒）
  └ 14:00 起     → 全部留给老婆

周日
  ├ 08:00–10:00  ★ 剪辑块 B（配音 + 对轨 + 配乐 + 字幕 + 封面 + 导出）
  ├ 10:00–11:00  缓冲
  ├ 午餐         → 用周五多做的那个菜
  ├ 18:00        发布（2 分钟）
  └ 14:00 起     → 全部留给老婆
```

### ⚠️ 两条不能破的边界

1. **周末剪辑块不能被切。** 它是全周唯一"受保护的连续块"，被切一刀整条成片链就断。**午餐靠周五多做的菜解决。**
2. **发布与评论不侵占家庭时段。** 评论回复窗口是 **发布后 24 小时内**，用**周一通勤 / 午休**回，不是周日晚上回。

## 三、三笔账怎么记（口径见核心参数表）

| 口径 | 稳态期（第10~12期） | 前 3 期（极简版） | 是否进判据 |
|---|---|---|---|
| **内容增量**（为拍摄多花的） | **≈5.2h** | ≈2.2h | ✅ **进** |
| **厨房基线**（本来就要花的 · 你出 50min） | 约 5h/周 | 约 5h/周 | ❌ **不进** |
| **每周附加**（评论 / 数据 / 选题补充） | 约 1h | 约 1h | ✅ 进 |

**时间块分配**

| 时段 | 时长 | 承担 |
|---|---|---|
| 通勤 + 午休 | 约 2.5h | 选题 / 脚本 / 评论回复 / 手机粗筛 |
| 周末剪辑块（2 天 × 2h） | 4h | 剪辑块 A + B |
| 周末其他 | 2h | 缓冲 / 补拍 / 传输 |
| **实际有效** | **约 6h** | 扣加班、产检、状态不佳 |

> ⚠️ **若通勤时段不可用**（自驾 / 骑行 / 公交太挤），选题与脚本只能挤午休和睡前 —— 那当周直接**降级为极简版**，不要硬撑。

## 四、单期流程

> 分环节时长以 [核心参数表 · 二](../00-核心参数表.md) 为准。此处只列**顺序与归属**。

| 步骤 | 放在哪 | 端 |
|---|---|---|
| 1. 选题（库里挑） | 通勤 | 手机 |
| 2. 写脚本（AI 辅助 + 改口语） | 通勤 / 午休 | 手机 |
| 3. **备菜**（老婆做；★ 要拍就先预留 **15min**） | 拍摄日傍晚 | 手机 |
| 4. **上镜清洁**（★ 在拍摄**之前**） | 拍摄日 18:40 | — |
| 5. **炒制 + 动作片段录制**（片段1 → 等待期做副菜+散热 → 片段2 → 片段3） | 拍摄日 18:50 | 手机 |
| 6. **成品热镜 ≤5min**（A 位起锅装盘 → 挪 B 位拍成品 / 夹一筷 / 封面） | 拍摄日 19:15 | 手机 |
| 7. 手机粗筛（删废条） | 通勤 | 手机 |
| 8. USB 传输 | 周六 10:00 | 电脑 |
| 9. 粗剪 | **周六上午** | 电脑 |
| 10. 掐时长 | 周六上午 | 电脑 |
| 11. 配音（安静房间补录） | **周日上午** | 手机 |
| 12. 对轨 | 周日上午 | 电脑 |
| 13. 配乐 + 字幕 | 周日上午 | 电脑 |
| 14. 封面 + 导出 | 周日上午 | 电脑 |
| 15. 发布 | 周日 18:00 | 电脑 / 手机 |
| 16. 评论回复 + 数据记录 | **24h 内，通勤时段** | 手机 |

> ⚠️ 任一步骤超出预算 → **降级，不加时长**。
> 降级优先级：减包装 → 缩短时长 → 改极简版（图文）。

## 五、存稿机制：攒**素材**，不攒成片

> 每周预算恰好等于 1 期产出，**没有多余的时间"多剪一期"**。
> 所以存稿靠**多拍**，不靠**多剪**。

| 规则 | 内容 |
|---|---|
| **做法** | 拍摄日**多录 1~2 个动作片段**（不要多做一道菜） |
| **攒的是什么** | **可用素材** —— ★ **按"分钟"记，不按"期"记** |
| **★ 别混口径** | **素材：3~5 分钟 / 期**；**成片：1 期**。目标栏里分开写 |
| **兑现** | 加班周 / 产检周 / 临产时，**只花剪辑时间**就能出片 |

| 项 | 值 |
|---|---|
| 常备 | **3~5 分钟可用素材 + 1 期成片** |
| **预产期前必须** | **≥2 期成片**（极简版也算）—— **截止 2027/4/1（第 25 周，孕约 36 周）** |
| **时间锚点** | ✅ **预产期 = 2027 年 5 月**（已确认）。降载窗口 **2027/4/1 – 6/12** —— 详见 [核心参数表 · 6.1](../00-核心参数表.md) |
| **可用攒稿窗口** | **2027/2/6 春节**（第 17 周）= 唯一长假。**阶段 1 窗口内没有任何法定长假** |

> ⚠️ **阶段 1 的 12 周内不必硬攒存稿** —— 截止线在 2027/4/1，距阶段 1 结束（2026/12/27）还有 3 个多月。
