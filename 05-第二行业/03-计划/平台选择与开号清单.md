# 平台选择与开号清单

> **一次性动作，Day 1 之前必须完成**，全程约 30~40 分钟。
> 目标：让「10/8 发出第一条视频」有一个真实存在的载体。
> 数字口径统一见 [核心参数表](../00-核心参数表.md)，本文不重复定义。

---

## 一、平台决策（先定这个，15 分钟）

### 1.1 候选对比

**必须单平台起步。** 多平台分发会让精力翻倍，直接违反时间约束。

| 平台 | 竖屏 | 美食赛道 | 新人冷启动 | 隐私 |
|---|---|---|---|---|
| **抖音** | ✅ 主推 | 极成熟 | 中（竞争激烈，但反馈最快） | 无社交推送 |
| **小红书** | ✅ | 强（生活/女性用户占比高） | **较易**（推荐更依赖内容标签，粉丝门槛低） | 无社交推送 |
| 视频号 | ✅ | 中 | 中 | ⚠️ **会推送给微信好友** |
| B站 | ❌ 横屏为主 | 中 | 高 | — |

### 1.2 核心权衡：抖音 vs 小红书

这两个是唯一值得纠结的，摆开摊说：

| 维度 | 抖音 | 小红书 |
|---|---|---|
| 流量上限 | **高**（公域推荐池最大） | 中 |
| 新人冷启动 | 难 | **较易** |
| 受众匹配 | 中 | **高**（"给老婆做饭 / 上班族"高度契合） |
| 数据反馈速度 | **快**（前 10 条就能看出完播） | 中 |
| 最适合 | **快速验证"我能不能持续产出"** | **找到精准受众、慢慢做** |

### 1.3 决策

| 项 | 结论 |
|---|---|
| **主平台** | **抖音** |
| **理由** | 阶段 1 的 KPI 只有一个——**验证"我能不能持续产出"**。抖音的数据反馈最快、最明确，能最早告诉你结果。 |
| **如果你更在意"受众精准"** | 改选**小红书**。它和"给老婆做饭 / 上班族"的匹配度确实更高，这是完全合理的替代方案。 |
| 暂不选 | 视频号（好友可见，隐私风险）；B站（横屏为主） |
| 第二平台 | **12 周之后再考虑**，现在不做 |

> ⚠️ **定了就不要改。** 中途换平台等于把冷启动重新走一遍。

### 1.4 隐私前置检查（★ 决定"要不要让同事知道"）

**视频号的每条内容都会分发给你的微信好友。**

如果你不想让锐捷的同事、领导知道你在做副业 → **直接排除视频号**。
（一并考虑你老婆的同事——她是医生，社交圈更敏感。）

**另外两条隐私提示**：
- 注册用的手机号**用你个人的，不要用工作号**
- 视频里的家人出镜规则见 [红线四](../01-战略与约束/约束与红线.md)：**老婆不露脸**

## 二、开号清单（20 分钟，逐条打勾）

### 2.1 注册与实名

- [ ] 用个人手机号注册
- [ ] **完成实名认证** —— 不做实名无法正常获得推荐，也无法开通创作者权限

### 2.2 完善资料（三件套）

> 📌 **昵称、头像、简介的完整方案与理由见 [账号身份方案](账号身份方案.md)。** 这里只列动作。

| 项 | 动作 |
|---|---|
| **昵称** | **「她点的菜」** —— 已定稿（2026-10-02）且**查重已通过**（抖音 / 小红书均未被占用），**直接设置即可** |
| **头像** | 用 `05-制作与素材/素材/头像/` 里选定的方案图（**方案 1 扁平插画**为推荐），需先确认 ≥200×200、方形 |
| **简介** | 用 [账号身份方案](账号身份方案.md) 的 **A 版**：`她点菜，我照做。` + `福州 · 程序员 · 每周一更` |
| 地区 | **福州**（有助同城推荐） |

> ⚠️ **简介与昵称都不得出现**「孕妇 / 孕期 / 医生 / 营养」——合规红线，见 [约束与红线](../01-战略与约束/约束与红线.md)。
> ⚠️ **昵称修改有频率限制**，尽量一次定对。

### 2.3 开通创作者权限 + 数据看板（★ 别跳过）

整套复盘体系要看完播率、3 秒跳出率，**没开通数据看板就会"有表无数据"，复盘彻底空转。**

- [ ] 路径：App →「我」→ 右上角菜单 → **创作者服务中心**
- [ ] **开通创作者权限**
- [ ] **开通数据看板**（部分数据需转专业号，或账号满 30 天）

### 2.4 关于"养号"：不存在这一步

平台官方已多次明确辟谣：**没有"养号"机制。**

新号完善资料后，**当天就可以发垂直作品**。

> 冷启动期播放低（0 播放 / 两位数）的真实原因是**内容数据不达标**，与"有没有养号"无关。
> **不要为此白等 3 天。** 那 3 天是免费的冷启动窗口，浪费掉很可惜。

## 三、发布设置

### 3.1 新号先短后长

行业实操：新号前几条用**短时长**更易过冷启动（完播率天然更高）。

→ **前 3 条走 30 秒**（正好与极简版形态一致），跑通后再逐步加长。

时长分档见 [核心参数表](../00-核心参数表.md) 第四节。

### 3.2 定时发布

可用范围以 [核心参数表](../00-核心参数表.md) 第五节为准。这里只给**操作路径**：

| 项 | 说明 |
|---|---|
| 位置 | **电脑网页端「创作者服务平台」** |
| 前置 | 实名认证 + 已开通创作者权限 |
| ⚠️ 限制 | **一旦提交不可修改** |

→ **如果不方便用电脑，就直接在周日 18:00 手机手动发**（设个提醒即可）。
**不要为了"定时"这个功能去折腾设备。**

### 3.3 话题标签

标签的实际权重**很低**。平台推荐的核心是「行为预测 + 内容标签 + 数据反馈」，其中：

- **内容标签**（标题关键词、口播词、字幕词、画面识别）比话题标签重要得多
- 话题标签只是辅助分类；堆热门大词反而**稀释账号画像**

→ **结论：4 个精准标签（1 主标 + 2 场景标 + 1 人群标）足够，不要在标签上花时间。** 把时间花在**标题关键词和口播内容**上。

### 3.4 发布时段

经验值：**美食 / 生活类的可用窗口是 11:30–13:00 与 17:30–19:00**（饭点前的决策场景）。

→ **周日 18:00 落在这个区间内，可用。** 这是"合理选项"而非"唯一最优"，不必纠结。

## 四、开号后不要做的事

| ❌ 不要 | 原因 |
|---|---|
| 同时发多个平台 | 精力翻倍，违反单平台起步 |
| 一上来就改名 / 改简介 | 昵称有修改频率限制 |
| 投流、买课、买设备（相机/稳定器） | **红线一：一次性 ≤￥400 且禁订阅** —— 投流和课程**永远不在**这个额度内 |
| 反复删了重发同一条 | 影响账号数据，且浪费时间 |
| 拿自己的号去刷别人的视频找灵感 | 与"养号"同理，无实际作用 |

## 五、开号前检查清单（打勾即完成）

- [ ] 平台已定（默认抖音）
- [ ] 视频号已排除，或已确认"不介意同事看到"
- [ ] 手机号注册 + 实名认证完成
- [ ] 昵称已查重、已定
- [ ] 头像已选定（96px 下能辨清）
- [ ] 简介已填，**不含合规词**
- [ ] 地区 = 福州
- [ ] **创作者权限 + 数据看板已开通**
- [ ] 账号与密码已记入密码管理器

> 完成以上，Day 1 就可以直接进入剪辑学习，不用再回头补这一步。
