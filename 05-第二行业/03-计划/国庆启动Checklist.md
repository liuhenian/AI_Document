## 1.2 ★ 开始前先认五件事

1. **假期这几天你是一个人** —— 买菜 / 备菜 / 炒 / 收拾全是你，**按 105 分钟/天**算，不是常态那 50 分钟。
2. **做菜不是"顺手"** —— 拍摄会在做饭之上**再加**一份活，并且让做饭本身变慢。
3. **"她"不在场，人设得在场** —— 用**微信远程点菜**：把她发来的消息**截图**（裁掉头像昵称），在电脑剪映里作图片轨插到前 2 秒。⛔ 不要用手机拍手机屏幕。
4. **国庆只求"跑通"，不求"做好"** —— 链路能走完 + 发出去，就算成功。
5. **★ 器材采购（一次性 ￥150~230）** —— 红线一已改为"**一次性 ≤￥400、禁订阅**"；**10/4 下单**：手机夹臂 ￥50~80 + 蓝牙快门遥控 ￥20 + 保鲜膜。⛔ **不要为等器材推迟拍摄**，10/11 第 01 期前到手就够。详见 [投入与器材清单](../01-战略与约束/投入与器材清单.md)。

**厨房拍摄铁律**

1. **先出菜，后补拍 —— 成品热镜另算**（做菜时手机只录着不挪不动；**出锅 0~2min 在 A 位拍起锅装盘**；**成品镜 ≤5min 拍完**）
2. **动作片段录制，每段 10~30 秒**（不录长段）；等待期**把手机拿到 ≥1m 外 + 拆壳 + 放通风处**
3. **全天搬机 ≤2 次**（只做 **1 道**主拍菜）；副菜**提前做好、只加热**（⛔ 不要"在等待期现做"，单灶眼做不了）
4. **⛔ 禁用数码变焦**（只用 1× 主摄）；接受 **A 位锅只占画面 1/4~1/3**，特写靠 **B1 的 40~50cm 近距离**
5. **★ 镜头贴超薄保鲜膜**（绷平贴镜、橡皮筋固定），⛔ 不用厚自封袋（折痕导致跑焦）
6. **★ 套膜后触屏失效** → **录前锁参数、启停不碰机身**（★ 有蓝牙遥控用遥控）
7. **★ 白平衡用 AWB（不手动）**（每块画面留白色参照 + 只留一个光源）、**曝光手动锁（ISO ≤800 / 快门随帧率）**；蒸汽镜头 ≥1/250
8. **⚠️ B 位不架 120~140cm 高架**（油烟机底部距灶台仅 65~75cm，会挡住镜头）→ **B1 固定在操作台边缘（夹臂）**；**B2 到餐桌、关厨房灯、只开台灯**
9. **拍摄全程关吸顶灯**（镜头和保鲜膜反光的主因）
10. **前 3 期不碰"整道菜都在爆炒 / 油炸 / 干煸"**，但**"先炒后炖、先煎后烧"可以**
11. **手上有油，永远不碰手机**
12. **上镜清洁排在拍摄之前**，不是拍完再擦
13. **★ 每期必须落"人话三句"**（0~2 秒她点的那句 / 中段一句自嘲或类比 / 结尾一句评价）—— **内容地板的第二条，不是"第 4 期才解锁"**

- [x] **★ 实测"油烟机挡不挡 B1"** —— 油烟机底部距灶台多少 cm？手持俯拍会不会顶到？ ✅ 2026-10-02

　 → ⚠️ **B2（餐桌）重点测**：关厨房灯、只开台灯，测够不够；**记下台灯的色温档位**
- [x] **★ 参数锁定** —— 专业模式：ISO/快门手动；**白平衡改 AWB**（手动 WB 已实测否决，自己调总偏色）；只用 1× 主摄 ✅ 2026-10-02

- [x] **跑一次 USB 传输** —— 建目录 → 连手机 → 选「传输图片」→ `Win+E` → 拖文件 ✅ 2026-10-02
