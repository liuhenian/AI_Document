## 1.1 〇、四个前提

### 1.1.1 假期这几天，你是一个人

买菜、洗切配、炒、洗碗、把灶台擦到"能上镜"，**全是你一个人**，没有帮手。
→ 这几天按 **[厨房基线 105 分钟 / 天](核心参数表)** 算，**不要按常态工作日那笔账（50 分钟）算**。

### 1.1.2 做菜不是"顺手"，是独立的一段劳动，而且会给它叠加负担

拍摄要在做饭之上**再加**一份活：搬机位、擦镜头、补拍、上镜清洁，并且会让做饭本身变慢。
→ 所以本计划把每天拆成**【厨房】/【视频】/【生活】三种块，分开记时**，不互相假装免费。

### 1.1.3 "她"不在场，但人设必须在场

账号是「**她点的菜**」。国庆老婆不在家，"点菜"这个动作演不了。
→ **用微信远程点菜**：让她发一条"想吃 XX"的消息。
→ **做法**：把聊天记录**截图**，裁掉头像和昵称、只留气泡，在电脑剪映里作为**图片轨**插到前 2 秒。
　 ⛔ **不要用手机去拍手机屏幕** —— 会反光、有摩尔纹，而且你还得腾出一只手。

### 1.1.4 国庆的验收标准：**链路跑通 + 内容至少"自己看得下去"**

- **必备①**：链路能走完（买菜 → 做菜 → 拍 → 剪 → 发）
- **必备②**：**内容过 9.1 内容地板** —— 前 3 秒有钩子 / 全片有"人" / 无 3 秒空档
- **不追求**：运镜、特效、稳定器级画面、精修调色

> ⚠️ **"自己都看不下去"不是审美问题，是 KPI 问题** —— 发不出去的东西，撑不到第 3 期。

### 1.4.1 ★ 厨房拍摄铁律（比上面三条更重要）

1. **先出菜，后补拍 —— 但成品热镜另算。** 做菜时手机只录着不挪不动；**出锅 0~2min 在 A 位拍起锅装盘**；**成品镜出锅 ≤5min 内拍完**（超时必跳色）。
2. **动作片段录制，每段 10~30 秒。** 不录长段；等待期**把手机拿到 ≥1m 外 + 拆壳 + 放通风处**（放灶边等于没停）。
3. **全天搬机 ≤2 次** —— 因为**只做 1 道主拍菜**；副菜**提前做好、只加热**（⛔ 不要"在等待期现做"，单灶眼做不了）。
4. **⛔ 禁用数码变焦**（只用 1× 主摄）。接受 **A 位锅只占画面 1/4~1/3**；要特写就用 **B1 近距离**拍。
5. **★ 镜头贴超薄保鲜膜**（绷平贴镜、橡皮筋固定），⛔ 不用厚自封袋（折痕导致跑焦）；**套膜后触屏失效 → 录前锁参数、启停不碰机身**（**有蓝牙遥控就用遥控**；没有才按音量键，但那会让画面歪）。
6. **★ 白平衡用 AWB（不手动）**（**每块画面留一块白色参照** + **只留一个光源** + 别让整画面被单一颜色占满）；**曝光手动锁（ISO ≤800）**，**快门随帧率**（30fps → ≥1/50；60fps → ≥1/100）；蒸汽镜头抬到 ≥1/250。
7. **⚠️ B 位不架 120~140cm 高架** —— 油烟机底部距灶台仅 65~75cm，会挡住镜头。**B1 用低架 / 夹臂固定在操作台边缘**（没夹臂前只拍摆好的静态"食材全景"，**切配手部放弃** —— 切菜时双手在刀和菜上，没人拿手机）；**B2 到餐桌，关厨房灯、只开台灯**。
8. **拍摄全程关吸顶灯** —— 它是镜头（和保鲜膜）反光的主因。
9. **前 3 期不碰"整道菜都在爆炒 / 油炸 / 干煸"的菜**，但**"先炒后炖、先煎后烧"完全可用**。
10. **手上有油，永远不碰手机。**
11. **上镜清洁排在拍摄之前**，不是拍完再擦。
12. **★ 每期必须落"人话三句"**（0~2 秒她点的那句 / 中段一句自嘲或类比 / 结尾一句评价）—— **这是内容地板的第二条，不是"第 4 期才解锁"**。
