# 极简版脚本卡（第 1~3 期专用）

> **用法**：每期复制一张，**10~20 分钟填完**。
> ⛔ **这不是《脚本模板》的低配版，是另一条路径** —— 第 4 期起换用 [脚本模板](脚本模板.md)。
> ⛔ **本卡不定义任何参数** —— 机位 / 音量 / 快门 / 镜头类型一律以 [核心参数表](../00-核心参数表.md) 为准。

---

## 五个格子（前 3 个动脑，后 2 个照填）

### ① 选题（1 行）

- **菜名**：
- **为什么是它**：（她点的 / 零翻车 / 有等待期能散热）

### ② 钩子（0~3 秒拍什么，1 行）

-

> ⚠️ **无口播期，钩子不靠话术，靠画面本身。**
> 标准：**不解释也想知道后面**的那种画面 —— 沸水翻滚 / 热油泼下 / 撕开 / 拉丝 / 码放整齐。
> ⛔ 别写"大家好"这类开场，也别指望字幕救场。

### ③ 分镜（8~10 行，**只填「画面」列**，每行 10~15 字）

| # | 秒 | 画面 |
|---|---|---|
| 1 | 0–3 | |
| 2 | 3–6 | |
| 3 | 6–10 | |
| 4 | 10–13 | |
| 5 | 13–16 | |
| 6 | 16–20 | |
| 7 | 20–23 | |
| 8 | 23–26 | |
| 9 | 26–30 | |

> ⚠️ **30 秒 / 每镜 2.5~3.5 秒**。这不是 [脚本模板](脚本模板.md) 里那套「60 秒 6 镜」骨架。
> ★ **分镜顺序 ≠ 拍摄顺序**。分镜是**剪辑顺序**，钩子镜头（通常是高潮动作）要放在第 1 位，拍摄时它往往是**最后一个才发生的**。
> 💡 列完对着「6 类镜头」过一遍，别让同一个画面出现 3 次以上。

### ④ 发布三件套

- **标题**：
- **话题**：1 主标 + 2 场景标 + 1 人群标（共 4 个）
- **时间**：周日 18:00

### ⑤ 发布后只记 3 个数（★ 别跳）

- **做饭净时长**：____ min
- **内容增量合计**：____ min
- **今天翻车了吗**：是 / 否 → 翻在哪一步：

> ⚠️ 只记这 3 个数，**不填完整的三笔账表**（那是第 10 期的事）。
> 但**必须记** —— 核心参数表里「拍摄附加 15min」是**设计值**，要用第 1 期的真实数字覆盖它。

---

## 前 3 期不做这些（别提前解锁）

| 推迟到 | 解锁什么 |
|---|---|
| **第 4 期** | 必拍镜头清单 / 拍摄清单 15 条 / 程序员比喻位 |
| **第 7 期** | 口播（钩子话术、每镜一句话、配音对轨）/ 收音音量细调 |
| **第 10 期** | 完整三笔账 / 发布前 9 条自检 |

> ⛔ **前 3 期唯一的任务：把链路跑通，连续发出 3 条。**
> 卡填得漂不漂亮，跟这件事一点关系都没有。

## 填好的示范：第 00 期（蒜蓉粉丝蒸虾）

**① 选题**：蒜蓉粉丝蒸虾 —— 她点过；有 6~8 分钟蒸制等待期（正好给手机散热）；蒸多一分钟不废。

**② 钩子**：热油泼在蒜蓉上，滋啦一声炸开。

**③ 分镜**

| # | 秒 | 画面 |
|---|---|---|
| 1 | 0–3 | 热油泼上蒜蓉，滋啦炸开 |
| 2 | 3–6 | 活虾在盆里弹动 |
| 3 | 6–10 | 剪刀开背，挑出虾线 |
| 4 | 10–13 | 粉丝泡软，剪两刀 |
| 5 | 13–16 | 虾尾朝外，码成一圈 |
| 6 | 16–20 | 双色蒜末铺满虾背 |
| 7 | 20–23 | 掀开锅盖，白汽冲起 |
| 8 | 23–26 | 筷子夹起一只，粉丝拉丝 |
| 9 | 26–30 | 空盘 + 字幕「第 1 道，她说还想吃」 |

> 注意第 1 镜：**泼热油是拍摄时最后才发生的动作**，剪的时候提到开头当钩子。

**④ 发布**：标题「她点的第 1 道菜 · 蒜蓉粉丝蒸虾」／`#新手做饭` `#福州家常菜` `#程序员的厨房`／周日 18:00
