# 学习与特色建设（一次性任务，不是每期重复）

> **起因**：2026-10-03 第 00 期素材拍完后，本人反馈 —— **"我的确能拍出东西，但东西不好用、没有特色，我自己都看不下去。"**
> **诊断**：这不是画质问题。六类镜头拍得再干净，换成任何一个人、拍任何一道菜都是那六类 —— **内容里没有"人"**。
> **性质**：**一次性建设**，在国庆内做完，之后每期只复用（+10 分钟）。**不计入单期内容增量判据。**
> 数字口径见 [核心参数表](../00-核心参数表.md)

---

## 一、三层归因：先修哪个

| 层级 | 症状 | 现在 | 成本 | 优先级 |
|---|---|---|---|---|
| **信息层**<br>为什么该看这道菜 | 看完了，但不知道"为什么值得看" | ❌ **空的** —— 六类镜头全是流程记录，没装任何"你的东西" | 极低（几行字幕） | **① 立刻修** |
| **结构层**<br>钩子与节奏 | 前 3 秒没有东西抓住人 | ⚠️ 弱 —— 质量地板要求"前 3 秒有钩子"，但**拍摄清单里没有任何镜头是为钩子拍的** | 低（学结构 + 掐节奏） | **② 一周内** |
| **画面层**<br>构图与运镜 | 构图乱、主体小 | ✅ **已能拍出东西** —— 不是当前瓶颈 | 中 | ③ 第 4 期后 |

> ⛔ **不要从第 3 层开始修。** 你现在看不下去，主因在第 1 层 —— 而第 1 层的修法**不需要任何设备、任何新技能**。

---

## 二、建设任务 A｜拆片 → 结构卡（约 2h）

**目的**：把"别人的成片"变成"你的施工图"。这是建立画面感**最快**的方法 —— 不是看教程，是**带着镜头意识去看**。

### A1. 选片（15min）

找 **10 条**同类视频，条件：

- 家常菜 / 一人食 / 新手做菜（**不要选探店、不要选专业厨师的精剪片**）
- 时长 **30~60 秒**
- 近 3 个月内发布（节奏会过时）
- ⚠️ **至少 3 条来自"粉丝 1 万以下"的号** —— 那才对得起你现在的阶段

### A2. 逐条记 4 列（60min，每条 6 分钟）

| # | 前 3 秒是什么（画面 + 字幕原文） | 共几镜 | 有没有"人"（说话 / 手 / 评价） | 哪一镜让我想继续看 |
|---|---|---|---|---|
| 1 | | | | |
| … | | | | |
| 10 | | | | |

> 💡 **第 4 列最关键。** 记完 10 条你会发现：让你想继续看的，**几乎都不是"好看的画面"，而是"我想知道结果"或"这个人有点意思"**。

### A3. 统计出三个数（20min）

- 前 3 秒**最常见**的是哪一类？（数字 / 疑问 / 冲突 / 结果前置）
- 平均**几镜**？（决定你的镜头数）
- "人"**第一次出现在第几秒**？（决定你把"她"放在哪）

### A4. 落成结构卡（25min）

**填完就是你的固定骨架，之后每期照填。** 存在本目录下，命名 `结构卡.md`。

```
【钩子模板】固定用哪 1 类：______（从拆片里挑最高频的）
【镜头数】______ 镜 × ______ 秒（从 A3 的统计来）
【人话三句的位置】
  0~2 秒  → 她点的那句话
  第 __ 秒 → 一句自嘲或类比
  最后 3 秒 → 她的评价 / 我的总结
【每期必做】前 3 秒必须是"结果前置"（先给一眼成品），不是食材全景
```

> ⚠️ **结构卡一旦定下，前 3 期不许改。** 换结构 = 每期重新学一遍。

## 三、建设任务 B｜特色定位：人话三句（约 1h）

**核心认知**：你的特色**不是厨艺**（你才学 1 个月），是 **"她 + 你 + 这个关系"**。而账号名「她点的菜」**已经把特色写在门牌上了** —— 只是内容里没兑现。

| 现成资产 | 别浪费它 |
|---|---|
| 「她点的菜」 | 这是一个**任务结构**：她点 → 我照做 → 她评价。天然有悬念（"她能吃到吗"） |
| 程序员 | 技术类比：火候 = 参数调优、备菜 = 预处理、翻车 = bug |
| 福州 · 闽菜 | 地域辨识度 + 当季食材 |
| **学厨 1 个月** | ★ **被严重低估**。"我也不会，我们一起试" —— 这个视角**比高手更有代入感** |

### 人话三句（每期固定三处，全部走字幕，零成本）

| 位置 | 写什么 | 例（蒜蓉粉丝蒸虾） |
|---|---|---|
| **0~2 秒** | **她点的那句话**（微信截图裁掉头像，或纯字幕） | "她说想吃虾，但不想剥壳。" |
| **中段** | 一句**自嘲或技术类比** | "开背这一步，跟改祖传代码一样——动之前先想清楚，改错了没法回滚。" |
| **结尾** | **她的评价 / 我的总结** | "壳是剥了的，她吃完了，没说不好吃。" |

> 💡 **这三句一共不到 60 字，但它是"你的视频"和"任何人的视频"之间唯一的分界线。**

### 写 10 条备选句（20min）

- 开场句 ×4（不同菜、不同语气）
- 中段类比句 ×3
- 结尾句 ×3

写进 `选题库.md` 备用，**不要每期现想**。

## 四、建设任务 C｜画面层：学构图，不学运镜（约 1h）

### C1. 为什么不学运镜（三条硬理由）

| 理由 | 说明 |
|---|---|
| **需要设备** | 推 / 拉 / 摇 / 移 / 跟依赖稳定器、滑轨 —— **而"稳定器"在 [投入与器材清单](../01-战略与约束/投入与器材清单.md) 的"明确不买"里**（全程固定机位，没地方用它） |
| **需要双手** | 你一只手在炒菜、另一只在拿锅铲 → **物理上做不到** |
| **会毁掉画面** | 镜头一动，观众注意力从**食物**转移到**镜头的晃动**上。而美食视频的"高级感"主要来自**食物本身的状态**（油花在跳、蒸汽在升），**固定机位才拍得清** |

> ✅ **验证方法**：在拆片时留意 —— 那 10 条里，**有几条是真的在运镜？** 你会发现绝大多数是固定机位。

### C2. 要学的：构图三条（立刻见效）

| # | 规则 | 怎么做到 |
|---|---|---|
| 1 | **主体占画面 1/3 以上** | A 位 1× 在 80cm 处锅只占 1/4~1/3 → **特写一律用 B1 的 40~50cm 近距离** 补，⛔ 不要靠数码变焦 |
| 2 | **背景干净** | 拍摄前把生活杂物从背景里拿掉（只留灶台 / 案板 / 锅）—— 这是"上镜清洁"的一部分 |
| 3 | **留白在动作的前方** | 锅铲往右翻 → 画面右侧留空；食材往锅里倒 → 落点在画面中下部 |

### C3. 要学的：景别三档（换景别 = 免费的"丰富感"）

| 景别 | 拍什么 | 用哪个机位 |
|---|---|---|
| **全景** | 灶台 + 锅（交代环境） | A |
| **中景** | 锅 + 手（交代动作） | A / B1 |
| **特写** | 食物表面 / 油花 / 蒸汽（交代质感） | **B1（40~50cm）** |

> 💡 **"丰富感"不靠运镜，靠"同一道菜用三种景别都拍到"。** 六类镜头本身就横跨三种景别 —— 你缺的是**把特写拍够**。

### C4. "动态感"的真实来源（不用运镜）

食材入锅、油花爆开、蒸汽升腾、揭盖、淋热油、汤汁翻滚、翻面 —— **这些是食物自己在动**。你的工作是**别错过它们**（这就是"动作片段录制 10~30 秒"存在的意义）。

## 五、每期怎么复用（+10 分钟）

| 步骤 | 时长 | 说明 |
|---|---|---|
| 按结构卡填"人话三句" | 5min | 从备选句库里挑 + 微调 |
| 按景别三档核对镜头 | 5min | 全景 / 中景 / 特写各有素材吗？特写够吗？ |

> **加到单期预算里：第 1~3 期 ≈2.2h**（仍在"✅ 正常"区间，见 [核心参数表 三、健康判据](../00-核心参数表.md)）

## 六、验收：发布前三问（"我自己看不下去"的判定）

发布前，自己看一遍，**三问全过才发**：

- [ ] **前 3 秒有没有一个"我想知道后面"的点？**（结果前置 / 疑问 / 她那句话）
- [ ] **30 秒里有没有一处"人"的痕迹？**（点菜 / 自嘲 / 评价 —— 至少一处）
- [ ] **有没有连续 3 秒以上"画面没变化、也没有信息"？**（有 → 剪掉）

> ⚠️ 这不是"提高标准"，这是**保 KPI 的必要条件**。KPI 是"连续 12 周不断更"，而**"自己都看不下去的东西，你发不到第 3 期"**。
