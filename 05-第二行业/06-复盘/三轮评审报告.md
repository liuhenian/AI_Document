## 一、评审机制

| 项 | 说明 |
|---|---|
| **评审员 A** | 资深项目管理与个人产能规划评审专家（关注时间预算自洽、目标可验证、KPI 设计、风险冗余、可执行性） |
| **评审员 B** | 资深短视频制作与内容运营专家（关注工时真实性、剪映操作准确性、厨房拍摄可行性、平台规则、合规、冷启动预期） |
| **轮次** | 3 轮「独立评审 → 修订 → 复审」闭环，两位评审员**互不通气** |
| 方式 | 只读评审，不修改文件；涉及平台规则处**联网核实** |

## 二、★ 终审判定（第 3 轮，两位独立给出）

| 评审员 | 结论 | 成功概率区间（连续 12 周不断更） |
|---|---|---|
| 规划视角 | **有条件能** | **40%~55%**（中位 ≈45%）；**若存稿前置未落实 → 降至 20%~30%** |
| 视频制作视角 | **有条件能** | **40%~55%**（中值 ≈47%）；**若采纳"前 3 期降配" → 上调至 55%~70%** |

### 两人独立收敛到同一个结论

> **v3 的问题是：把"跑通"和"做好"绑在了同一天。**

一个零基础的人，第一周要同时做「固定机位 + 补 5 类必拍镜头 + 后期补录口播 + 逐句对轨 + 贴图小人」——**大概率在第一个周日 11:00 的硬截止点前做不完**，而排期**没有任何缓冲**吸收这次超时 → 节奏一碎，R01 弃坑期提前引爆。

### → v4 的核心改动：**形态阶梯**

| 期次 | 形态 | 单期预算 |
|---|---|---|
| **第 1~3 期** | **极简版**：30 秒、固定机位、**无口播**（全靠字幕）、不做必拍清单、不做贴图 | **1.5~2.5h** |
| 第 4~6 期 | + 必拍清单 | 2.5~3.5h |
| 第 7~9 期 | + 口播（后期补录 + 对轨） | 3.5~4.5h |
| 第 10~12 期 | 稳态 | 4.5~5h |
| 第 13 周起 | 解锁贴图小人进画面等 | — |

> **这一改同时解决三个 P0**：前 3 期按熟练值记账、素材量与"先短后长"打架、无缓冲吸收第一次超时。
> 代价：**没有**。12 周目标、发布频率、红线一条都没动。

## 三、三轮问题汇总

### 第 1 轮：11 个 P0 + 15 个 P1

| 类别 | 主要问题 |
|---|---|
| **P0** | ①无平台/开号前置 ②"降级权（隔周1期）"与"连续12周不断更"直接对立 ③单期4h判据漏算工作日投入 ④剪辑90min vs 180min ⑤孕产期风险被错误标记"已解除" ⑥厨房收音方案不成立（全指向麦克风会收录油烟机噪声）⑦孕妇饮食+医生身份踩医疗合规红线 ⑧剪映免费额度未提示 ⑨工时估算失真 ⑩封面规范缺失 ⑪"顺手拍"素材量不够 |
| **P1** | 国庆强度对零基础不现实、"70%就走"与"必须发视频"冲突、KPI无质量地板、发布档期自相矛盾、加班潮未概率化、阶段2不可验证、里程碑与"不看数据"打架、Day编号对不上、"周日剪"与"两天剪"不一致、厨房拍摄零方案、贴图小人方案自相矛盾、冷启动预期无依据、音乐版权、音量路径、码率选项 |

**重要遗漏风险**（第 1 轮挖出）：孕产期情绪与家务、主业加班潮、平台合规、家人态度变化、选题枯竭、隐私出镜边界、主业精力恶化、弃坑可能提前到第 2~3 周。

**遗漏环节**：账号注册与实名、发布时间策略、话题标签、评论区运营、封面尺寸、音乐版权、合规、剪映免费墙、厨房拍摄物理方案、账号简介、数据指标定义、不投流后果。

### 第 2 轮：发现"改了 15 条，但埋了 2 个新雷"

| 主要发现 |
|---|
| **P0-1 存稿缓冲在时间上不成立** —— 周末 6h 装不下第二期；"保护机制自己就是断更源" |
| **P0-2 单期核心 3.5~4.5h 是错数字** —— 各环节相加实为 4.5~5h；而健康判据、周预算、阶段 2 门槛全挂在它上面 |
| **P0-3 阶段 0 / 阶段 1 边界未定义** —— 10/8（周四）首条与"周日档期""12 周起算"衔接空白 |
| **最结构性的诊断：缺单一事实源（SSOT）** —— 同一个数字被抄了 3~5 份，改漏一份就产生矛盾。**v1 的矛盾是"写错了"，v2 的矛盾是"改漏了"** |
| 新的硬矛盾：15 个片段 vs 20~40 个；"拍老婆吃的反应" vs "老婆不露脸"；"养号"与官方辟谣冲突；定时发布仅电脑端；创作者中心未提 |

### 第 3 轮：终审，3 个残余真问题

| # | 问题 | v4 处理 |
|---|---|---|
| 1 | **存稿机制仍不成立** —— 窗口内（10/11–12/27）**无任何法定长假**；且"缓冲"与"存稿"共用同一池子 | 改为**「存稿周」机制**（预产期前指定 2~3 周，当周发极简版，省下的 3h 多产 1 期）；并明确**"预产期前，缓冲让位于存稿"** |
| 2 | **单期核心下限算错**（270 应为 275）；**判据 ≤5h 低于自身区间上界 5.1h**，正常慢速周会被误判偏紧 | 改正为 **275~305min**；判据上移到 **≤5.5h** |
| 3 | **前 3 期按熟练值记账 + 素材量与"先短后长"打架 + 无缓冲** | **形态阶梯**（见第二节） |
| 4 | SSOT 迁移没做完（"预产期前存稿 ≥3 期" vs ≥2 期等 6 类残留） | 全部修正；冷启动表、健康判据表改为**只引用不抄** |
| 5 | 贴图小人：账外成本 + "固定"是新手最易做不固定的东西 + 降级第一刀 → **每周一次自我否定** | 前 12 周**只作头像，不进画面**；第 13 周解锁 |

## 四、v4 之后的剩余风险（无法靠文档消除）

### 不可控（知悉即可，不必焦虑）

| 风险 | 说明 |
|---|---|
| **R03 预产期/月子期** | 纯医学事件，无法排期。**唯一能对冲它的就是存稿** |
| **新手摩擦系数** | "配音 30min、对轨 20min"是**熟练值**；新手第一期做对轨可能是 60~90min |
| **单机位厨房拍摄的体力消耗** | 双手占用、油烟糊镜头、拍到一半要翻面；30~45 次"停手-开录-停录" |
| **合规判定的随机性** | 文档能规范措辞，不能消除平台判定随机性 |
| **平台规则变动** | 剪映会员化、推荐机制调整 |
| **个人韧性** | 内在变量 |

### 可控（但需要你动手）

| 项 | 动作 |
|---|---|
| ★ **预产期未确定** | **今天就去确认并写进日历**。没有这个日期，"预产期前存稿 ≥2 期"是无法执行的空话 |
| **存稿恒为 0** | 执行「存稿周」机制 |
| **第 01 期零缓冲开局**（10/9 复工 → 10/11 发布，生产窗口仅 8h） | 可用极简版顶（1.5~2.5h），压力大减 |

## 五、评审员的共同提醒（值得单独记住）

> ### 规划视角
> **「文档正在变厚，可用信息密度在下降。」**
> 全库约 4.4 万字，通读要 1.5~2h = **每周预算的 25%~35%**。
> **下一个版本该做减法，不该再加精度。**
> 并且——「把 4.4 万字、3 轮评审、SSOT、R01–R08 编号用在'每周做一顿饭的口播'上，是**完美主义换了个战场**。**写作的确定性，替代了发布的焦虑。**」

> ### 视频制作视角
> **「不是卡在'不会剪'，而是卡在'周日 11:00 前做不完'。第一次做不完，节奏就碎了。」**
> 最可能的失败窗口：**第 3~5 周**（约 10 月底–11 月中）。
> 触发因素**大概率不是临产**（那会被"不可抗力"条款豁免），**而是"一次普通加班周"** —— 因为加班导致的断更**不在豁免范围内**。

## 七、如果只记得三件事

1. **前 3 期做极简版。** 不要一上来就做完整版。
2. **今天就确认预产期。** 这是全部风险预案里唯一的时间锚点。
3. **KPI 只有"不断更"。** 不看播放量、不看粉丝、不看收益——前 12 周。
