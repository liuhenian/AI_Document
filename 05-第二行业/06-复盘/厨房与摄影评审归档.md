## 一、评审机制

| 项 | 内容 |
|---|---|
| **对象** | 「她点的菜」美食短视频方案 —— 重点是**"做菜 / 买菜 / 备菜"这条被漏掉的账** |
| **触发** | 用户指出：原方案的拍摄计划里**完全没有考虑做菜本身**（只有"拍摄"，没有"做饭"） |
| **评审员 A** | 资深中餐厨师 + 家庭厨房运营顾问（20 年灶台经验） |
| **评审员 B** | 美食短视频摄影师 + 家庭厨房拍摄顾问（手机竖屏 / 夜间室内 / 油烟环境） |
| **规则** | 两位**互不通气**、独立出具 P0/P1 清单；每轮发现阻断性缺陷即**打回重改**，改完复审 |
| **是否打回的判据** | **文档逻辑错误 / 物理上不成立 → 打回**；**仅需实测数据验证 → 不打回，转"落地必须验证事项"** |
| **硬件前提** | HUAWEI Mate 70，**一块手机**；**零补光设备**；红线 = 金钱投入 0（不买灯、不买设备、不买会员）<br>⚠️ **2026-10-03 前提已变更**：红线一改为"一次性 ≤￥400、禁订阅" → 本轮的"零成本兜底"结论**仍成立**（免费方案永远是第一步），但"不要写加灯"这类表述已解除 |
| **时间前提（用户澄清）** | **常态工作日**：老婆备菜、买菜提前买好 → 厨房成本 **50min**；**国庆等独自期**：全自理 → **105min** |

### 用户给出的两条关键修正（贯穿全程）

1. **国庆只有一个人** → 假期那几天按 105min/天算，但**不要把常态工作日也按 105 算**（常态备菜是老婆做的）。
2. **原声不是全要也不是全不要** —— **保留关键动作原声**（下锅 / 淋油 / 切菜），环境原声压低，BGM 最低。

## 二、第 1 轮｜发现"厨房完全不在账上"

### 评审员 A（厨师）· P0

> **厨房隐性劳动完全不在账上。**
> 买菜、备菜（洗/切/配/腌）、炒制、收拾 —— 这四个环节在方案里**一个都不存在**，全被塞进"拍摄"里当 0 成本。结果是：一个每天要花 1~1.5 小时的劳动，在计划里**成本记 0**。

### 评审员 B（摄影）· P0

> **最可能先崩的不是剪辑，是"第一次真下厨还带拍"。**
> 剪辑可以慢慢学，但"一手锅铲一手手机"是一次性的现场压力 —— 火候不等人，拍废了菜就废了。

### ★ 双方独立撞到的同一个 P0

> **十一老婆不在家 → 「她点的菜」人设不成立。**
> 两个人各自独立发现：账号人设是"她点菜"，但国庆期间"她"不在场，**"点菜"这个动作演不了**。
> → 处理：改用**微信远程点菜 + 截图**（裁掉头像昵称，作图片轨插到前 2 秒）；⛔ 不用手机拍手机屏幕（反光 + 摩尔纹 + 还得腾一只手）。

### 产出

按第 1 轮意见重写 v2：三笔账分离、2 机位、先出菜后补拍、微信远程点菜、攒素材。

## 四、第 3 轮（终审 · 审 v3）｜两位独立判 ❌

### 评审员 A（厨师）结论

| 编号 | 判定 | 理由 |
|---|---|---|
| P0-1 搬机次数 | 已消除 | "一期只做 1 道菜"把 B→A→B 锁死为 2 次；但代价是晚饭只能 1 道 |
| P0-2 长镜头 vs 分段录 | 已消除 | 两窗口各 60~90s、中间停机，互斥描述已删干净 |
| P0-3 补拍耗时 | 部分消除 | 15min 进了账，但"摆盘 1.5min"是外行数字；账②与账③单列重复口径 |
| P0-4 攒素材 vs 成片 | 未消除 | 账②仍全用"期"计价，"素材=半期/成片=一期"没写成判据 |
| P0-5 午餐备好 | 未消除 | 周五多做一菜只覆盖**周末**午餐；常态工作日"提前备好午餐"仍无买菜/备菜时点 |
| P0-6 Day 2 菜凉 | 部分消除 | 6h40 能塞下，但出现 12:00 午饭 + 14:35 再吃饭的双餐；出锅 14:20 到动筷 14:35 隔 15min，热菜已转温 |

**v3 新引入的问题**
1. **账③常态漏算"拍备菜 15min"** → 应为 125min（18:40–20:45），不是 110min
2. **"只做 1 道菜"与"这是一顿家庭晚饭"未对账** —— 饭桌要 2 道则炒制 25→50min，账③崩到 150min
3. 窗口1 停机后等待期"无事可做"是**伪冲突**（人本就在灶前盯炖）；真冲突在**成品**：窗口2 录的"刚起锅"与 15min 后补拍的"冷成品"颜色/勾芡/绿菜不一致，剪辑必跳戏

**厨房实操隐患**
1. **1.5~2× 数码变焦**：夜间 ISO≤800 下裁切 ≈ 等效 540p，必糊；且 55~65cm 对爆炒油星根本不够远，油膜 3~5s 糊镜
2. **靠"停机 3~8min"散热**：灶边 40~60℃，停机不降温，重启必再触发静默停录。真解是后撤 ≥1.5m + 拆壳 + 风冷
3. **擦镜 10min 控反光**：家庭反光源是顶灯，擦不掉；该**关顶灯 + 侧向补光**
4. 把"淋热油/揭盖"当唯一高潮：油泼烟大、揭盖蒸汽直冲镜头，恰是**最易糊镜**的两个动作
5. **热菜出锅 15min 后再拍成品**：炖菜出水、勾芡返稀、绿叶转黄

**选题池容量**
> "不碰油炸 + 旺火爆炒"砍掉川菜核心（回锅/宫保/干煸/水煮）与全部镬气小炒，中餐"爽感"来源废掉约七成。剩下的炖/蒸/汤/卤大多 >40min（红烧肉 60、牛腩 90），与"40min 出锅"相冲。四条件交集估算仅 **6~8 道**，12 期**凑不齐且必撞重复**。

**裁决：❌ 不能进终审。** 必修：①账③改 125min 重排；②补拍拆两级；③明确"1 道主拍=晚饭 1 道"；④数码变焦/散热改物理方案；⑤先排 ≥12 道候选菜单。

### 评审员 B（摄影）结论

| 项 | 判定 | 理由 |
|---|---|---|
| 搬机次数 | 部分消除 | 机位段写"全天 ≤2 次"，但补拍预算自己写"搬机 2~3"，两处打架；含补拍实际 4~5 次 |
| 长镜头 vs 分段 | 已消除 | 60~90s 远低于 8~15min 静默停录阈值，机械矛盾解决 |
| 补拍 15min | 未消除 | "补拍食材全景"逻辑不成立 —— 菜已出锅，生食材全景只能备菜期拍 |
| 攒素材 vs 成片 | 部分消除 | "第1~3期≈2.2h"没说清是每期还是三共享，口径含糊 |
| Day2 菜凉 | 部分消除 | 补拍排在吃饭前解决了"凉"，但揭盖蒸汽只有出锅后 1~2min，搬机+摆盘约 5min 后蒸汽全散 |
| 8.5h 排满 | 已消除 | Day2 缩到 6h40，且属假期 |

**v3 新引入的问题**
1. **补拍毁成品（新 P0）**：绿叶菜 8~10min 塌黄、红烧油面结膜、蒸汽归零；封面 9:16 成品照晚拍 15min = 暗哑无热，前 3 秒钩子直接废
2. **节奏 vs 字幕冲突**：30 秒 10~14 镜 = 每镜 1.5~3 秒，1.5 秒读不完一句字幕 —— 无口播全靠字幕，二者互斥
3. **淋热油节点错位**：耐拍菜的"淋热油"多在**出锅后**，v3 把它放在窗口1（下锅段），动作节点不对
4. **60~90s 够剪不够挑**：窗口1 里真"下锅+淋油"仅 3~5s，其余是等待/空镜；要凑 5~7 个 A 位镜得在同一 clip 反复切，容错低

**实拍翻车点**
- **白平衡**：油烟机灯 ≈3000~3500K，与吸顶灯混光下手机自动 WB 漂移，青菜发暗绿、肉发灰黄 —— v3 全程没提锁 WB
- **30~45° 反光**：油面 + 不锈钢灶台镜面反射油烟机灯，下锅瞬间一片高光过曝
- **俯拍 50~60°/120~140cm**：手会挡光并投硬影；夜间单光源影子跟着手抖
- **油膜糊镜**：55~65cm 淋热油，60~90s 内镜面必起油雾
- **数码变焦 1.5~2×**：夜间低照度 = 裁切 + 信噪比翻倍，正好撞 ISO>800 红线
- **快门 1/60**：手部仍拖影；揭盖蒸汽在 1/60 糊成白团，蒸汽要 1/250+

**零设备约束的现实性**
> 两块白板只"搬光"不"造光"。油烟机灯下灶台(A)或有 100~400 lux，但餐桌(B)高处俯拍离灯远，实测常 30~80 lux —— **B 位必挂**。
> "300 lux 是报警器不是解药"：v3 判"不达标就加灯"，而红线禁加灯 → 无兜底。

**裁决：❌ 不能进终审。**

## 五、第 4 轮（复核 · 审 v3.1）｜两位独立判 ❌

### v3.1 改了什么

账③重排 ｜ 补拍拆两级（出锅 0~2min A 位热镜 + B 位成品镜 ≤5min）｜ 1 主拍 + 1 副菜 ｜ 禁用数码变焦 + 套袋 + 后撤散热 ｜ 动作片段录制 10~30s ｜ 选题池放宽 + Day 3 排 ≥12 道菜单 ｜ 6 类镜头 ｜ 节奏改 2.5~3.5 秒/8~10 镜。

### 评审员 A（厨师）结论

| 必修项 | 判定 | 理由 |
|---|---|---|
| 账③改 125min | 部分修复 | 时间线重排成立、算术自洽（50+15+10+25=100）。但缩短全押在"拍摄附加 25→15"，**无一秒实测支撑** |
| 补拍拆两级 | 已修复 | 逻辑闭环。唯一缺口：端菜上桌+摆盘会吃掉 5min 配额 |
| 1 主拍 + 副菜 | 部分修复 | "副菜在等待期做"与"等待期仅 3~8min"**自相矛盾** —— 3~8 分钟做不熟一道副菜，单灶眼也无法并行 |
| 物理方案替变焦 | 部分修复 | 方向对。但 70~90cm 机位与"后撤 ≥1m"打架，且"连续片段录 10~30s"没有停机窗口供散热 |
| 先验 12 道菜单 | 部分修复 | 12 道仍是"待做"，交集风险未实证 |

**新引入问题**：搬机口径自洽但**灶眼/时间不自洽**（单灶眼做饭，主菜占锅时副菜无位）；15min 是拍脑袋；1× @70~90cm 锅占宽约 25%，"画质＞构图"是免责声明不是方案。

**裁决：❌ 打回。** 剩 4 条必修：顶灯反光、自封袋起雾、副菜自洽、125min 与 15min 附加。
**自封袋专答**：防油膜 ✅、防蒸汽雾 ❌ —— **把"永久油膜"换成了"临时雾膜"**。
**副菜专答**：**不成立**。等待期正要盯收汁防糊，此时抢第二灶做副菜 = 分心 + 争火，负担是叠加不是隐藏。

### 评审员 B（摄影）结论

| 必修项 | 判定 | 理由 |
|---|---|---|
| 补拍顺序 | 已修复 | 0~2min 抓装盘蒸汽油光，成品窗压到 ≤5min，全景回归备菜期 |
| 照度兜底 | 部分修复 | "跟油烟机灯正下方"是真招（正下方 200~400 lux）；但台灯缺色温/距离/角度三参数，且与 3200K 冲突 |
| 口径统一 | 已修复 | ≤2 次搬机自洽，无内部矛盾 |
| 补参数 | 部分修复 | 参数齐、禁数码变焦对；但 70~90cm 让特写缩水、自封袋表述过于乐观 |
| 节奏字幕 | 已修复 | 节奏与字幕不再互殴 |

**特别复核**
- **自封袋**：厚 PE 自封袋折痕多 → AF 对到膜面跑焦、反光、雾化。正确戴法是**超薄保鲜膜绷平紧贴镜头（膜距 <1mm）**。套袋后**触摸失效**，只能录前锁参 + 物理键启停。
- **B 位高度**：油烟机底距灶台仅 **65~75cm**，**120~140cm 已高过油烟机**，俯拍 50~60° 时油烟机挡在镜头与食物之间，**根本架不住**。
- **家用台灯**：真能提亮（50cm 处约 500~1000 lux），但多为 2700K 暖 / 6000K 冷，与油烟机灯 3200K **二次混光**，锁 3200K 反致偏色。
- **1× + 70~90cm**：Mate 70 主摄 ≈27mm，竖屏 80cm 处水平视野 ≈107cm，**30cm 锅只占 1/4~1/3**。

**裁决：❌ 打回。** 剩 4 条必修：B 位布光重做、台灯单光源、保鲜膜绷平贴镜、反光与手挡硬影。
