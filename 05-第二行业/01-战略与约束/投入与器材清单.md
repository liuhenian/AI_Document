# 投入与器材清单

> **本文件是"花多少 / 买什么 / 先买什么"的唯一来源。** 金额与档位只在这里定义，其他文档只引用。
> 红线口径见 [约束与红线 · 红线一](约束与红线.md)。
> 起因：2026-10-03 —— 本人确认"**不是零投入，可以接受少量投入**"，红线一由"绝对 0"改为"**有限额的一次性支出**"。

---

## 〇、先立边界，再列清单

| 允许 ✅ | 禁止 ⛔ |
|---|---|
| **一次性**支出，**累计上限 ￥400** | **订阅型**支出：会员、投流、云服务（每月都在扣） |
| 耗材（保鲜膜等），**≤￥10/月** | 单件 ≥￥100 却**没先承诺"用它拍完下期"** |
| **家里已有的先用完**，再买 | 相机、稳定器、课程、剪辑外包 |
| 坏了可以再买同款 | 单件 ≥￥500（超过即视为"投资"，本项目不是投资） |

**为什么"少量"要写成"上限"而不是"随便花"：**

从"0"改成"少量"，真正危险的不是那三百块，是两件事 ——
1. **订阅型**：会员 / 投流是**持续**扣款，会一直跟着你；
2. **没有上限**：一旦"少量"变成"看着办"，器材就会一点点吃掉本该用来拍的时间。

所以新口径是：**一次性、有总额、禁订阅。** 出这个范围，红线照旧亮红灯。

## 一、排序原则：先"不报废"，再"好不好看"

> **KPI 是连续 12 周不断更 → 素材报废是致命的，画质低一点不致命。**

所以花钱的优先级是：

```
① 冗余 / 机位固定  ← 消除"整期报废"的风险
② 光              ← 提升画质上限（可缓，先做免费方案）
③ 声音 / 美术      ← 第 7 期要口播了才轮到
```

⚠️ **顺序不能反。** 先买灯、后买夹臂，等于**先花钱提升上限，却还留着会让整期报废的洞**。

## 二、T0｜先把免费的用完（￥0）★ 买任何东西之前先做

| 动作 | 解决 |
|---|---|
| 砧板挪到**油烟机灯正下方**的操作台 | B1 从 30~80 lux → 200~400 lux（**最大的免费增量**） |
| **拍摄全程关吸顶灯** | 去掉反光主因 + 去掉混光 |
| B2 到餐桌：**关厨房灯、只开一盏台灯** | 单光源 → AWB 才准 |
| 白案板 / 白纸**背光侧 + 食物正下方**各一块 | 补暗部 + **兼作 AWB 锚点** |
| **错峰录音**（切配时油烟机本来不用开） | 拿到干净的刀工声 |
| 顶灯**色温可调 → 调到最暖档**，与油烟机灯一起开 | 光量接近翻倍（**先试这个，不花钱**） |

> ✅ **做完 T0 再实测一次**：ISO 是否 ≤800、快门是否 ≥1/50。
> 　**能过 → T2 那盏灯可以缓，甚至不用买。**
> ⚠️ **T0 没做完就买灯，是在为"本来免费能解决的问题"付钱。**

## 三、T1｜￥150~230（★ 起手档：只买"消除报废"的东西）

> 这一档**不提升画质**，只保证"素材不会白拍"。按优先级排。

| # | 项 | 价 | 解决什么 | 验收标准 |
|---|---|---|---|---|
| 1 | **手机夹臂**（万向/魔术臂 + 台面夹） | ￥50~80 | ★★ **B1 切配的机位固定**（见下方"为什么排第一"） | 录完回放，**画面里的静止物体（灶台边）无肉眼漂移**；换景 **≤3 分钟** |
| 2 | **蓝牙快门遥控** | ￥20 | ★★ 套膜后触屏失效，**按物理键会让机身位移**（一天几十次启停 = 几十次歪掉） | 遥控启停，**画面不抖**；单手可操作 |
| 3 | **保鲜膜**（耗材） | ￥10~20 | 开工率 —— 唯一纯粹正向的支出 | 每段录完能立刻换一张 |
| 4 | **白色餐盘 / 白色砧板**（家里缺才买） | ￥15~30 | 免费反光板 + **AWB 锚点** + 画面底子 | AWB 回放白盘**不偏色** |
| 5 | 充电宝 + 短线（10000mAh 起） | ￥50~80 | 灶边录制耗电快。⚠️ **Mate 70 电池大概率够用 → 只有真遇到过掉电再买** | 连续拍 1 小时不断电 |

### 为什么"夹臂"排第一 —— 它补的是**方案自己的一个漏洞**

方案里 B1 写的是"**手持**离菜 40~50cm 俯拍"。

**但切配时，你的双手在刀和菜上 —— 没有手拿手机。**

所以"手持"这两个字，**在"切配手部动作"这个镜头上根本不成立**。三个后果：

- 6 类镜头里的第 2 类（切配 / 手部）**只能放弃**，或
- 变成"先摆好再切"（**摆拍切菜 = 表演**，懂行的观众一眼看出），或
- 用"垫书 + 米袋"硬凑 → 要俯拍 50~60° 时书堆很难稳，**每次微调都要重新堆**

**夹臂把手机夹在操作台边缘 / 吊柜上，从上方俯拍** → 切配镜头才真的拍得到，而且**人不用管手机**（这正是"把拍摄占用的注意力压到最低"的本意）。

> ⚠️ **选型要点**：① 夹口能夹 **≥5cm 厚**的台面；② **臂长 ≥40cm**（臂太短俯不下去）；③ 承重 **≥1kg**。
> 　 ￥50~80 档完全够用，**不必买专业影视级的**（那些是给相机用的）。

### 为什么"蓝牙快门遥控"排第二

方案里写"套膜后触屏失效 → **用音量键启停**"。这句话本身是对的，但有个副作用没被算进去：

**按音量键 = 手必须碰机身 → 每次启停画面歪一点。** 一天下来 20~30 次启停 = 20~30 次位移，而**每次都要重新对角度**。

而且启停的时刻，恰好是你**手上有油/水**的时候 —— 也就是那条"永远不碰手机"的铁律最容易被违反的时刻。

￥20 的蓝牙快门（自拍杆那种），**启停完全不碰机身**。

> 💡 **先试免费的**：如果你有**华为手表 / 手环**，先确认它能不能当遥控快门（部分型号支持）。**能用就不买。**

## 四、T2｜再 +￥150（提升画质上限，**视实测决定买不买**）

| # | 项 | 价 | 买它的**真正**理由 | 触发条件 |
|---|---|---|---|---|
| 1 | **LED 补光灯** | ￥120~200 | **不是"更亮"，是"入射角可控"** —— 顶光拍食物是平的、没有阴影层次；**侧 45° 才有食欲质感** | **T0 做完 + T1 到手，实测仍 ISO >800** 才买 |
| 2 | 柔光（白纸 / 薄白布） | ￥0~20 | 光质变柔，去掉硬阴影 | 随灯 |

**选灯 5 条硬要点：**

1. **CRI ≥95**（显色指数 —— 低于这个数，菜会发灰、发死）
2. **色温 2700~6500K 连续可调**（要能调到与油烟机灯接近，否则又变成混光）
3. **无频闪**（有频闪 = 画面出现横向条纹，**且手机上回看不明显**）
4. **能夹 / 能挂**（放台面会占地、挡手）
5. **220V 供电优先**（电池灯会掉亮度、色温会漂）

> ⛔ **不要往头顶再加一盏灯** —— 那只是把"顶光"变亮，不解决"顶光难看"。灯必须放**侧前方 45°**。
> 💡 **免费的替代**：厨房顶灯若色温可调 → 调到暖档与油烟机灯接近，**两盏一起开**，光量接近翻倍。**这个不花钱，先试。**

**验收**：ISO 是否掉到 ≤800；食物朝镜头那面是否**不再整片发黑**；有没有出现横条纹。

## 六、⛔ 明确不买（写清楚，防止日后手痒）

| 不买 | 为什么 |
|---|---|
| **投流** | KPI 是"不断更"，不是播放量。**零投流起号慢是已知代价**，不是缺陷 |
| **稳定器 / 滑轨** | 全程固定机位，**没地方用它**；且要双手 + 空间 |
| **相机** | 换机 = 把学习成本重来一遍，与"前 12 周只求跑通"直接冲突 |
| **麦克风（现在）** | 见 T3 —— 现在买闲置 4 周 |
| **剪辑软件会员** | 前 3 期**用不到任何会员功能**（字幕手动加也行） |
| **桌面三脚架** | **给不了俯拍**（俯拍要悬臂 / 夹臂）→ 要买就买 T1 的夹臂 |
| **存储卡** | 每期素材仅 3~5 分钟，1080P 约 100MB/分钟 → **一期不到 1GB**，内置存储足够；买卡反而多一个"忘插卡 / 导错盘"的出错点。（真要扩容，**先确认本机是否支持 NM 卡**，不支持就别看） |
| **餐具 / 桌布套装** | "高级感"与"不断更"无关，且与 T1 的白盘功能重叠 |
| **课程 / 训练营** | 免费信息足够。当务之急是**把 12 期拍完**，不是学更多 |

## 七、★ 三条防膨胀规则（比清单本身更重要）

> 开这个口子之后，最容易发生的坏结果不是"多花三百块"，是**用买东西来缓解焦虑，同时让流程变复杂到拍不下去**。

| # | 规则 | 防的是什么 |
|---|---|---|
| 1 | **新器材上线前，先承诺"下周就用它拍完一整期"。做不到 → 退掉或收起来** | **器材幻觉** —— 买了灯就觉得"现在才叫能拍"，结果流程变长、更不想开灶 |
| 2 | **单件 ≥￥100，先用它换 4 期已发布作品；换不回来 = 买早了** | **消费替代创作** —— 用"买"来缓解"没人看"的焦虑 |
| 3 | **每加一件器材，搭建 + 撤收必须 ≤3 分钟。超时即淘汰** | **流程膨胀** —— 每天只有 2h（做饭那晚只有 100~115min），流程一长就直接威胁发布 |

> ⚠️ 规则 3 是硬指标，因为**拍摄日的总占用已经是 100~115min**，任何"多摆一样东西"都在往那条 20:20~20:35 的线上压。

## 九、这笔钱在财务上的位置

按 [核心参数表 · 6.1](../00-核心参数表.md)：家庭收入**单点化**（配偶收入为 0）+ **2027/5 新生儿**。

- ￥400 一次性 ≈ **家庭月收入的 2.7%**，**不产生任何月供**；
- 对照：一台入门微单 ￥4000+，**且要重新学一遍**；
- 结论：**这笔投入的规模是"试错成本"，不是"投资"。**

> **判断它值不值的标准，不是"画质提升了多少"，是"有没有让 12 周更容易走完"。**
