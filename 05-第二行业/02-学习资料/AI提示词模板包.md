# AI 提示词模板包

> 直接复制发给任意大模型（Claude / GPT / DeepSeek / 豆包 都行）。
> 你的优势：**你是做 AI 助手规划的人**，这块你应该用得比普通博主更狠。
> **版本：v4（经 3 轮评审修订）**

---

## 使用原则

| 环节 | 用 AI 的力度 |
|---|---|
| 选题、脚本、标题、钩子、评论回复 | ✅ **重度使用（纯赚）** |
| 封面图、配图、空镜转场 | ⚠️ 克制使用 |
| 卡通小人逐帧动画 | ⛔ 不做（见[约束与红线](../01-战略与约束/约束与红线.md)） |

> **"有意思"优先用文案和人设实现，而不是用制作实现。**
> 前者是资产（越攒越强），后者是消耗（每期重来）。

## 0. 全局人设（每次对话先发这段）

```
你是我的短视频内容助手。我的人设固定如下，之后所有输出都基于这个设定，不要跑偏：

- 身份：程序员，在锐捷做网络设备监控系统（APM）开发，此前做过多年通信协议开发
- 生活（**仅作你的理解背景，不得出现在任何文案里**）：在福州，正在学做闽菜；老婆是医生，正在怀孕
- 账号定位（对外表述）：一个做监控系统的程序员，给我老婆做饭
- 内容形式：竖屏美食短视频。**第 1~3 期 30 秒（无口播，全靠字幕）；第 4~6 期 30~45 秒；第 7 期起 45~75 秒**
- 语言风格：说人话、不端着、带点程序员式的冷幽默（用代码/系统思维打比方）
- 观众：在福州生活的年轻人、想学做饭的上班族
- 禁忌：不油腻、不煽情、不喊口号、不用网络烂梗

【合规硬约束，任何输出都必须遵守】
- 不使用"孕妇餐""孕期营养""孕期食谱"这类表述，统一说"给我老婆做的家常菜"
- 不宣称任何健康功效（如补铁、下奶、对胎儿好、缓解孕吐）
- 不做饮食禁忌清单（如"孕妇不能吃什么""这些调料别碰"）
- 不提及、不暗示"我老婆是医生"，不借医生身份做任何背书
- 不提供任何医疗、营养、诊疗建议
- 如我给的选题或文案触碰以上任一条，请直接指出并给出合规改写版本

确认后回复"已接收"，之后按我指令输出。
```

## 1. 批量出选题（Day 3 用）

```
基于我的人设，帮我出 30 个短视频选题。

要求：
1. 分成 4 类，每类 7~8 个：
   A. 给我老婆做的家常菜（结合福州当季食材）
   B. 程序员快手菜（下班 30 分钟内能做完）
   C. 学做闽菜/福州菜的踩坑过程（可自嘲）
   D. 程序员思维讲做饭（用代码/系统打比方）
2. 每个选题写成一句话，10~18 字
3. 每个选题后标注：这条的"钩子"是什么（观众为什么点进来）
4. 优先考虑福州本地食材和时令
5. **每个选题标注难度：★（一台手机+做饭顺手拍就能做）/ ★★（需要更多拍摄或制作时间）/ ★★★（前 12 周不要做）**
6. **合规检查：如某个选题涉及孕期营养、健康功效、饮食禁忌，或需要我老婆以医生身份出现，请标出来并给出合规改写版本**

输出格式：编号 | 选题 | 钩子 | 难度
```

## 2. 写 30 秒脚本（Day 4 用；前 3 期不做口播，字幕为主）

```
按下面结构，为选题「XXX」写一条 60 秒短视频脚本。

结构：
- 钩子（0~3 秒）：一句话抓人，要有悬念或反差
- 主体（3~50 秒）：
  · 分 3~4 个镜头/步骤，每步一句口播
  · 口播要口语化，像跟朋友说话
- 结尾（50~60 秒）：留人话术，引导关注或评论区互动

要求：
1. 全片口播字数控制在 150~180 字（60 秒的语速）
2. 每个镜头标注【画面】（拍什么）+【口播】（说什么）
3. 至少用一处程序员式比喻（如"火候是个死循环，得 break"）
4. 不要开场白（"大家好我是…"），直接进钩子
5. 不要喊"点赞关注"这种硬广，用自然方式带出
6. **口播必须口语化**：写完后逐句念一遍，拗口的地方改掉，别留"AI 腔"
7. **合规自查**：检查是否出现功效宣称、饮食禁忌、医生身份，如有请直接改写
8. 另外附一份【必拍镜头清单】：食材全景 / 下锅 / 起锅装盘 / 成品特写 / **自己尝或拍手（不得拍老婆露脸）**，各 1 条

输出：分镜表 + 必拍镜头清单
```

> ⚠️ **第 1~3 期用法不同**：极简版**不需要口播**，请改为输出「**3~5 句短字幕**」+「**3 类镜头指令**（食材全景 / 下锅长镜头 / 装盘特写）」，不要写分镜表和口播稿。

## 3. 批量起标题（Day 3 用）

```
为这条视频起 10 个标题：
【视频内容】：（一句话描述）

要求：
1. 每个标题 ≤15 字
2. 至少包含：1 个好奇心型、1 个反常识型、1 个代入感型
3. 不用"震惊""必看""干货"这类词
4. 允许带一点点自嘲
5. 标注每个标题的打法（为什么这么起）

最后推荐 1 个，说明理由。
```

## 4. 改前 3 秒钩子（最重要的单点优化）

```
这是我视频的开头 3 秒：
【原文】：XXX

请给我 5 个替代版本。

要求：
1. 每个都能让观众"不划走"
2. 方法不限：制造悬念 / 抛反常识 / 直接给冲突 / 提出疑问
3. 每个版本 **≤15 字**（这是质量地板的硬标准），必须口语化
4. 标注每个用的什么技巧

按"抓人程度"从高到低排序。
```

## 5. 封面文案（Day 5 用）

```
为这条视频设计封面。

【视频内容】：
【目标情绪】：（震撼 / 好奇 / 亲切 / 搞笑）

给出：
1. 三组封面大标题（每组 ≤6 字，要能在缩略图上秒读）
2. 每组配的副标题（≤10 字）
3. 建议的画面主体是什么（食物特写 / 人物表情 / 对比图）
4. 建议用什么颜色做主色

说明每组的适用场景。
```

## 6. 评论区回复（冷启动期必用）

```
这是我的视频，有人评论了：「XXX」

请帮我起草 2 条回复：
1. 一条：真诚回应，拉近距离
2. 一条：顺势引导（引到下一条内容或引发更多讨论）

要求：口语化、别客套、别用"感谢支持"这种模板话。
```

## 7. 周复盘辅助（每周日用）

```
这周我发布了第 N 期视频，数据如下：
- 播放量：
- 完播率：
- 点赞/评论/收藏：
- 涨粉：

我自己的判断：（写你的感受，比如"开头太平""节奏拖"）

请帮我：
1. 从数据里找出最值得改的 1 个指标（不要贪多）
2. 给出下一期的 1 个具体改进动作（要可执行，不要说"提升质量"）
3. 提醒我哪些数据现在看是没意义的（避免我被数据带偏）

注意：我现在处于"连续 12 周不断更"阶段，KPI 是不断更，不是数据。
如果数据很差，请先肯定"我还在更"，再谈改进。
```

## 8. 卡壳时用（第 3~8 周高危期）

```
我现在不想做这期视频了，觉得没意义、没人看。

请：
1. 用 3 句话说清楚：我现在放弃的话，实际损失是什么（要具体，不要鸡汤）
2. 给我一个"最低成本完更"的方案（比如：这期做一个最简单版本，能交差就行）
3. 提醒我当初开始的原因

不要说"加油你能行"，直接给判断。
```

> 这条是专门为**第 3~8 周弃坑期**准备的。存在这里，卡住的时候直接复制。

## 附：AI 不该做的事

| 别让 AI 做 | 原因 |
|---|---|
| **每期重新生成**"你的卡通形象" | 角色一致性差，每期都不一样，观众出戏。**正确做法：只在最初生成一次（或直接用手绘/表情包截图），之后一直复用同一张** |
| 生成 3~5 个"同一形象不同表情"的图 | AI 做不到形象一致，会反复重抽浪费时间。改用换脸/换表情包 |
| 生成逐帧动画 | 时间成本 2~5h，直接违反时间约束 |
| 代写"鸡汤式结尾" | 油腻，和人设冲突 |
| 一次生成 10 期脚本 | 你剪不完，反而增加焦虑 |
| 生成"孕妇营养/孕期禁忌"类内容 | **合规红线**，会导致限流或账号处置 |

## ⚠️ 合规提醒（v2 新增）

大模型不知道你的平台规则，**它很可能会主动给你生成踩红线的文案**（比如"这道菜含铁丰富，适合孕期"）。

**每次拿到 AI 输出后，必做一次合规自检**：
- [ ] 有没有功效宣称？
- [ ] 有没有饮食禁忌暗示？
- [ ] 有没有借"老婆是医生"背书？
- [ ] 有没有用"孕妇餐/孕期营养"这类词？
