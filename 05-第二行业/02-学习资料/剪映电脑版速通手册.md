# 剪映电脑版速通手册

> **这是你的主力工具。** 手机只负责「拍」和「粗筛」，剪辑、导出、后期动画都在电脑做。
> ⚠️ 剪映界面随版本变化。**找不到功能时，直接看软件右上角的「快捷键」按钮**，或用面板搜索框搜功能名。
> 手机版操作见 [剪映手机版速通手册](剪映手机版速通手册.md)。

---

## 0. 装什么、怎么装

| 项 | 说明 |
|---|---|
| 软件 | **剪映专业版（Windows）** ← 官网 `capcut.cn` 下载 |
| 环境 | 推荐 Windows 10 及以上 64 位 |
| 登录 | 按提示登录。**建议用你注册账号的那个抖音号登录** —— 生态打通，以后的模板/素材能共用 |
| ⛔ 不要装 | PR、达芬奇、AE —— 前 12 周用不上，装了就分心 |

**免费版足够跑完前 12 周。** 唯一要知道的限制：智能字幕有额度（各来源说法不一）→ **先攒好素材再一次性识别，别反复重来**。

## 1. 界面认路（电脑版布局）

打开剪映 →「开始创作」→ **先设参数**（见下）→ 进入编辑界面。

```
┌──────────┬──────────────────┬────────────┐
│  素材库   │     预览区        │  属性面板   │
│ （左上）  │    （中上）       │  （右侧）   │
│  导入素材 │                   │ 位置 / 缩放 │
│  音频     │                   │ 音量 / 颜色 │
│  文本     ├──────────────────┤            │
│  贴纸/特效│      时间轴        │            │
│          │  主轨 / 音频 / 字幕 │            │
└──────────┴──────────────────┴────────────┘
```

| 区域 | 是什么 |
|---|---|
| **左上 素材库** | 导入的素材在这；音频/文本/贴纸/特效也从这进（⛔ 后三个前 12 周忽略） |
| **中上 预览区** | 看效果，下面有播放/暂停 |
| **下 时间轴** | **主战场**。默认三层：主视频轨 / 音频轨 / 字幕轨 |
| **右 属性面板** | 选中素材后改参数（位置、缩放、音量、颜色） |
| **右上角** | **导出** + **「快捷键」按钮（★ 记住它）** |

### 新建项目时先设这两个

| 项 | 值 |
|---|---|
| 分辨率 | **1080p** |
| 帧率 | **30fps** |

> 选错的话，导出时可能被拉伸或掉帧。

## 2. ★ 快捷键表（程序员的主场）

**鼠标悬停在任意按钮上会显示它的快捷键；右上角「快捷键」按钮可看完整列表**（暂不支持自定义）。

| 操作 | 快捷键 |
|---|---|
| **分割** | **`Ctrl + B`**（部分版本为 `Ctrl + K`） |
| 删除选中片段 | `Backspace` / `Delete` |
| 撤销 | `Ctrl + Z` |
| 恢复 | `Ctrl + Shift + Z` |
| 导入素材 | `Ctrl + I` |
| 复制 / 粘贴 | `Ctrl + C` / `Ctrl + V` |
| **导出** | **`Ctrl + E`** |
| 播放 / 暂停 | `空格` |
| 时间轴放大 / 缩小 | `Ctrl + +` / `Ctrl + -` |
| 吸附开关 | `N` |
| 全屏 | `Ctrl + F` |
| 新建草稿 | `Ctrl + N` |
| 时间线上下滚 / 左右滚 | `滚轮` / `Alt + 滚轮` |
| 手动踩点 | `Ctrl + J` |

> **前 12 周只需记住 4 个**：`Ctrl+B` 切、`Delete` 删、`空格` 播、`Ctrl+E` 导。
> 其余不用背，手熟了自然记住。

## 3. 核心操作（与手机版一一对应）

### 3.1 导入素材

- **方法一**：把视频文件直接**拖进素材库**面板
- **方法二**：直接拖到**时间轴主轨**最左侧
- **方法三**：`Ctrl + I` 呼出导入窗口

> ⛔ **不要双击视频文件** —— 那会打开预览窗，不会进时间线，容易卡住。

### 3.2 分割（对应手机版的"分割"）

1. 把**播放头（白色竖线）**移到切割点，停稳
2. 按 **`Ctrl + B`**
3. 原来的一段变成两段；按错了按 `Ctrl + Z`

### 3.3 删除

选中片段 → 按 **`Delete`**。删完后前后片段会**自动吸附靠拢**，不用手动挪。

### 3.4 裁剪（电脑版比手机版强的点）

手机版只能"分割 + 删除"；**电脑版可以直接拖片段边缘**缩进缩出，一步到位。

> ⚠️ 只对**已分割的片段**生效 —— 没分割就拖边框，整段会跟着位移。

### 3.5 字幕

1. 顶部菜单【**文本**】→【**智能字幕**】
2. 选"识别全部" → 等进度条走完
3. 字幕自动落到**字幕轨**，双击某一行改字
4. 右侧属性栏调**字号 / 颜色** → **务必勾选「描边」**（白字在亮背景上根本看不清）

### 3.6 音量

选中片段 → **右侧属性面板**里找音量；或选中音频轨上的片段直接调。

- 视频原声：100（或按需）
- **背景音乐：15~20**（人声必须压过音乐）

### 3.7 导出

右上角【**导出**】或 `Ctrl + E`：

| 参数 | 设值 |
|---|---|
| 格式 | MP4 |
| 分辨率 | **1920 × 1080** |
| 帧率 | **30fps** |
| 码率 | **推荐** ← ⚠️ 电脑版独有档位，手机版通常没有 |

> ⛔ 不要选 4K（文件大、上传慢）。

## 4. 电脑版 vs 手机版：差异速查

| 项 | 手机版 | 电脑版 |
|---|---|---|
| 裁剪 | 只能"分割 + 删除" | **可直接拖边缘** |
| 快捷键 | 无 | **全套键盘快捷键** |
| 码率档位 | 通常没有 | **有（推荐 / 较高）** |
| 素材面板 | 无独立面板 | **有素材库** |
| 批量操作 | 难 | **可框选多个片段** |
| 后期动画小人 | ❌ 做不了 | ✅ 能做（第 13 周解锁） |
| 便携性 | ✅ 随时 | ❌ 要坐电脑前 |

> **结论**：日常剪辑用电脑；**碎片时间（通勤 / 午休删废镜头）用手机**。

## 5. 常见卡点

| 卡点 | 解法 |
|---|---|
| 双击文件没进时间线 | 那是预览。改用**拖拽** |
| 找不到功能 | 右上角「快捷键」按钮 / 面板搜索框 |
| 拖边框整段位移 | 先按 `Ctrl+B` 分割，再拖 |
| 字幕看不清 | 属性栏勾选**描边** |
| 剪完发现没声音 | 选中片段 → 右侧面板查音量是否被关掉 |
| 导出很慢 | 正常，1080P/30fps 是平衡点 |
| 智能字幕额度用完 | 手打（口播稿现成，复制粘贴 + 对齐），或用手机语音转文字 |
| 想加转场 / 动画 | ⛔ 前 12 周不要 |

---

## 6. ⛔ 前 12 周禁用清单

- ⛔ 转场、特效、滤镜、调节（调色）
- ⛔ 关键帧、蒙版、抠像
- ⛔ 多机位
- ⛔ 逐帧动画小人
- ⛔ 依赖会员的 AI 降噪 / 人声分离

> **前 12 周你需要的 80% 只有：导入、分割、删除、排序、字幕、导出。**
