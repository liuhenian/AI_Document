# 素材

> 按 `第XX期/` 分目录存放原始素材。
> **拍完当天就导入归档，别攒。**

## 目录规范

```
素材/
├── 第01期/
│   ├── IMG_xxx.mp4
│   └── ...
├── 第02期/
└── ...
```

## 纪律

- 每期发布后：**删废料**（占空间，且会让下次找素材变慢）
- 手机拍摄参数：**9:16 竖屏 / 1080P / 30fps**
- 素材不提交 git（大文件）。建议在仓库 `.gitignore` 中排除：
  ```
  05-第二行业/05-制作与素材/素材/
  05-第二行业/05-制作与素材/成片/
  ```
