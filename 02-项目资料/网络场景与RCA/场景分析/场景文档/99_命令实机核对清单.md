# RGOS 排查命令实机核对清单

> **用途**：本清单汇总 11 份场景文档第 4.3 节出现的全部排查命令。凡标注「待核对」的，表示该写法尚未在真机/模拟器上确认过，**发布给一线前必须先核对**。

> **背景**：两位评审专家在评审中指出，原始工单里完全没有排查命令记录（对 889 条工单全文检索，`display`、`show ip cef`、`show ip fpm` 等出现 0 次），因此无法从数据侧验证命令的准确性，只能逐条实机核对。

## 三、已知的厂商风格错误（评审已确认，v1→v2 已修正）

| 错误命令 | 问题 | 修正 |
|---|---|---|
| `display web` | 华为风格；RGOS 只有 `show`，无 `display` | 改为 `show` 写法 |
| `show ip cef` | Cisco 专有 CEF，RGOS 无此命令 | 改为 `show ip fib` / `show forwarding-table` |
| `show ip fpm` | 非 RGOS 术语 | 删除，硬表侧统一 `show ip fib` |
| `show star run` | 非规范连写缩写 | 改为 `show startup-config` |
| `show interface aggregate` | 写法不规范 | 改为 `show aggregatePort summary` |
