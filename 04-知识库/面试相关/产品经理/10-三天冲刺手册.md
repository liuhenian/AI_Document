### 1.3 时间紧张时的裁剪顺序

【核心】如果只有 3 天，按这个顺序砍：

1. **先砍【细节】标记的所有内容**（省约 1.5 小时，损失极小）
2. **再砍题库中的【支撑】与【细节】题**（省约 2 小时）
3. **再砍精讲 05 的生态与商业模式部分**（面试问到概率中等，可临时查）
4. **绝对不砍**：[[03-精讲-智算网络与无损以太|精讲 03]] 第 3、4、7、10 节（无损三件套、PFC 四风险、选型、训练慢定位）、[[02-精讲-Overlay与EVPN|精讲 02]] 第 2、4、8 节（封装、五类路由、MTU）、[[06-精讲-路由协议BGP与OSPF|精讲 06]] 第 3、4、6 节（两个状态机 + 机制到规格的映射）——**JD 点名了 BGP 与 OSPF，这三节被问到是必然。**

## 5 必背数字卡

【核心】这些数字是"专业度信号"，用错比不知道更糟。

| 数字 | 事实 | 用在哪 |
|---|---|---|
| 50 字节 | VXLAN 外层开销（14+20+8+8） | MTU 与丢包排障 |
| 24 位 / 1600 万 | VNI 位宽与容量 | 多租户规模 |
| 4094 | VLAN 上限 | 为什么上 Overlay |
| 4789 / 4791 | VXLAN / RoCEv2 的 UDP 端口 | 抓包与哈希 |
| 802.1Qbb | PFC 标准号 | 无损机制表述 |
| 802.1Qaz | ETS 标准号 | 区分于 PFC |
| 82 ns / 20 ns | 1 KB 报文在 100G / 400G 的串行化时延 | 时延预算 |
| 3 跳 | Spine-Leaf 任意两点跳数 | 时延可预测 |
| ×2 | 交换容量 = 端口数 × 速率 × 2 | 规格对比 |
| 1024 卡 | 64×400G 两层 + 8 网卡服务器的规模 | 会算账 |
| 1:1 / 1:3 | 无阻塞 / 常见收敛比 | 成本与架构 |
| 51.2T / 102.4T | 主流交换芯片容量代际 | 产品代际 |
| 112G / 224G | SerDes 单通道速率 | 端口上限 |
| 3.3 ms × 3 | BFD 最快检测时间（生产常用 50 ms × 3） | 高可用表述 |
| TCP 179 | BGP 的传输层端口 | 抓包与防火墙放通 |
| 19 字节 | BGP 报文公共头（16+2+1） | 报文结构题 |
| 10 s / 40 s | OSPF Hello / Dead 定时器 | 收敛时间推算 |
| 60 s / 180 s | BGP Keepalive / Hold Time | 为什么"收敛慢" |
| 100 Mbps | OSPF 默认参考带宽（所以 10G 与 100G 开销都是 1） | cost 陷阱题 |
| 1 跳 | eBGP 默认 TTL | 非直连必须 multihop |
| 800G / 1.6T | 2026 规模化 / 小批量节奏 `[待核实]` | 趋势判断 |
| 15%–20% | CPO 在高端交换机渗透率 `[待核实]` | 技术路线 |
| 2025-06 | UEC 1.0 发布 `[待核实]` | 标准演进 |
| 12 个月 | EOL 提前通知期 | 生命周期管理 |
| 90 秒 | 单个案例讲述时长 | 行为面试 |
| 300 字/分钟 | 中文理解型阅读速度 | 时间预算依据 |

| 4 | Spine-Leaf 恒 3 跳，时延可预测 | 为什么这对 AI 重要？ |
| 5 | 64×400G 两层 = 1024 卡 | 想上万卡怎么办？ |
| 6 | 大 DC 用 eBGP：扩展、策略、隔离、体系一致 | 代价是什么、怎么补？ |
| 7 | M-LAG 双活可逐台升级，堆叠单控制面 | 客户只有 2 次维护窗口选谁？ |
| 8 | VXLAN 开销 50 字节，VNI 24 位 | MTU 要配多少？ |
| 9 | EVPN 五类：一发现二找人三广播四选主五网段 | Type-3 管什么？ |
| 10 | 分布式网关让东西向一跳直达 | 代价是什么？ |
| 11 | 对称 IRB 才撑得住大规模 | 非对称为什么会崩？ |
| 12 | AI 看 JCT，不看平均带宽 | JCT 与 MFU 什么关系？ |
| 13 | Ring AllReduce 最慢卡决定整环 | 所以网络该优化什么？ |

## 7 面试前 72 小时清单

### 7.1 知识与材料（T-3 天）

- [ ] 三套速测卷核心题正确率 ≥ 85%
- [ ] 3 个 STAR 案例写完并录音过一遍（F-003、F-004、F-006）
- [ ] 我方三条产品线 + 三个关键规格写成一张纸
- [ ] 必背数字卡能默写 15 条以上

### 7.2 信息校准（T-2 天）

- [ ] 官网最新产品页与方案页（确认规格口径，删掉记不清的型号）
- [ ] 最近一次发布会/财报中网络业务表述
- [ ] 目标客户近期招标与中标信息
- [ ] 行业近三个月热点（UEC 进展、800G/1.6T、CPO）

### 7.3 临场准备（T-1 天）

- [ ] 白板三张图能在 60 秒内画出：Spine-Leaf、无损闭环、训练慢定位树
- [ ] 准备 3 个反问（产品路线、考核指标、当前最大短板）
- [ ] 复述一遍"三类判断"开场框架
- [ ] 早睡。**智算那一节的状态比多背两道题重要。**

### 7.4 面试当天的话术锚点

【核心】当被问到不会的问题时，用这个结构，不要硬编：

> "这块我没有直接做过。我的理解是 A（基于已知原理），如果要确认，我会看 B（某个指标或文档）。你们现在的做法是怎样的？"

**这个回答的分数高于胡编。** 面试官考察的是判断力与诚实度，不是知识面。
