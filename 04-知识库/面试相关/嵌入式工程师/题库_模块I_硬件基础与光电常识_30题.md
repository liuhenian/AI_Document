## 一、单项选择题（12 题）

### I-001 ★
3.3V CMOS 输出直接驱动 5V TTL 输入，通常：
A. 不能工作
B. 可以工作（3.3V CMOS 的 VOH ≈ 3.3V 高于 5V TTL 的 VIH=2.0V）
C. 需要串联大电阻
D. 只能输入低电平

**答案：B**
**解析**：电平兼容要看三参数：驱动侧 VOH ≥ 对方 VIH，驱动侧 VOL ≤ 对方 VIL，且电压不超对方耐受。5V TTL 输入高门限仅 2.0V，3.3V 输出轻松满足；但**反方向**（5V TTL 输出→3.3V CMOS 输入，VIH≈2.31V）多数情况可行但需查具体芯片（5V 输出高电平最低 2.4V，裕量小）；5V CMOS（VIH=3.5V）与 3.3V 系统互连则必须电平转换。A/C/D 不成立。
**知识点**：硬件-逻辑电平

### I-002 ★★
MCU 的 GPIO 配置为“开漏+外部上拉”的典型用途是：
A. 提高驱动电流
B. I2C 总线、多设备线与、电平转换（上拉到不同于 MCU 的电压轨）等场景
C. 降低功耗
D. 加快翻转速度

**答案：B**
**解析**：开漏输出的“只能拉低”特性构成线与（见模块 G-006），且上拉电阻的电源轨可以与 MCU 不同（如 3.3V MCU 开漏上拉到 5V，天然升压电平转换）。A 反了——开漏驱动能力弱（靠上拉），高电平驱动电流为零；C 不一定；D 反了——上升沿由 RC 充电决定，比推挽慢。
**知识点**：硬件-GPIO 开漏

### I-003 ★★
芯片每个电源引脚旁边并接 0.1µF 电容的目的是：
A. 储能供芯片长时间断电使用
B. 高频去耦：就近提供瞬态电流、吸收电源噪声，保证电源完整性
C. 滤除 50Hz 工频干扰
D. 保护芯片过压

**解析**：芯片内部晶体管同时翻转时瞬间电流冲击很大，PCB 走线电感会造成功率轨电压跌落（di/dt 效应），去耦电容就近储能把瞬态电流“就地供应”，避免电源轨弹跳引发的误动作。搭配大容量（10µF+）钽/陶瓷电容构成宽频段低阻抗网络。C 的 50Hz 滤除靠大电容且主要是电源级的事；D 是 TVS/压敏电阻的职责。
**答案**：B
**知识点**：硬件-去耦电容

### I-004 ★★
示波器探头打在 ×10 挡的作用与代价是：
A. 信号放大 10 倍便于观察
B. 探头阻抗变为 10MΩ//小电容，降低对被测电路的负载效应，适配更高带宽；代价是信号被衰减 10 倍，需注意示波器通道探头比设置
C. 保护示波器不超过量程
D. 提高垂直分辨率

**答案：B**
**解析**：×10 挡把输入阻抗从 1MΩ//~100pF 提到 10MΩ//~15pF——**对高频信号尤其关键**：100pF 在 10MHz 时阻抗仅约 160Ω，会严重加载被测总线（测 I2C 波形变圆、测晶振直接停振都是探头电容惹的祸）。代价：幅值衰减 10 倍，若示波器未识别探头比，读数差 10 倍。低幅小信号且频率低时用 ×1。A/C 恰说反；D 与衰减方向相反。
**知识点**：硬件-示波器-探头

### I-005 ★★
用示波器测量 MCU 的 32.768kHz 晶振输出，接上探头后系统停振了，最可能的原因是：
A. 晶振坏了
B. 探头电容（×1 挡约 100pF）加载了振荡回路，破坏了起振条件
C. 示波器带宽不够
D. 触发电平设错

**答案：B**
**解析**：32kHz 晶振的负载电容通常仅 6~12pF，振荡回路的能量极小，探头电容一接上直接“闷死”振荡器。正确做法：①用低容探头（有源探头或 ×10 挡 ~10pF 也不保险）；②测晶振的另一个脚（驱动端幅度大）；③用高阻缓冲器/场效应管跟随器隔离；④干脆通过 MCU 的 MCO 引脚输出时钟来测。**“一测就停振”是嵌入式调试经典现象，答出探头电容机理是加分点。**
**知识点**：硬件-晶振测量

### I-006 ★★
示波器“触发（Trigger）”的作用是：
A. 放大信号
B. 让波形在屏幕上稳定显示：每次扫描从满足触发条件的位置开始，波形不再左右“乱跑”
C. 自动测量频率
D. 保护输入端

**答案**：B
**解析**：没有触发时 ADC 采样起点随机，周期信号在屏幕上漂移。边沿触发是最常用方式；调试串口/单次事件用**单次触发（Single）**抓毛刺与上电时序；抓偶发异常用脉宽触发/欠幅触发。**嵌入式高频用法：触发在复位引脚上升沿，单次抓取上电时各路电源与时钟的上电顺序**——这是软硬件联调排“启动偶发失败”的标准手段。
**知识点**：硬件-示波器-触发

### I-007 ★★
逻辑分析仪相比示波器的核心优势是：
A. 垂直精度更高
B. 多通道（16/32/64 路）+ 协议解码（SPI/I2C/UART/CAN 原码级还原），适合调试总线时序与软件时序
C. 带宽更高
D. 能测模拟毛刺

**答案**：B
**解析**：逻辑分析仪只判高低电平（1bit 通道），换来的是海量通道与深存储，配合协议解码器直接显示“MOSI: 0xAB，CS 有效”，还能用多路 GPIO 并行观察任务调度时序（任务切换打标记）。模拟细节（边沿质量、振铃、幅值）必须靠示波器——**两者是互补关系：先逻辑分析仪看“协议对不对”，再示波器看“波形质量好不好”。**
**知识点**：硬件-逻辑分析仪

### I-008 ★★
透镜焦距 f 与物距 u、像距 v 满足高斯成像公式，正确的是：
A. 1/f = 1/u + 1/v
B. f = u + v
C. 1/f = 1/u − 1/v
D. f = uv

**答案**：A
**解析**：薄透镜成像公式 1/f = 1/u + 1/v（符号约定按实正虚负）。光电调试的实际应用：激光测距接收端聚焦光斑到探测器光敏面，知道探测器尺寸与距离即可算所需焦距/透镜口径；调焦不准时光斑弥散、信号幅度骤降——“软件怎么看都收不到足够光强”的机械光学原因。B/C/D 均为错误公式。
**知识点**：光学-成像公式

### I-009 ★★
光电二极管工作在“光伏模式”与“光导（反偏）模式”的区别，正确的说法是：
A. 两者完全相同
B. 光伏模式零偏置（暗电流小、噪声低、线性好），适合弱光精密测量；反偏模式响应快、结电容小，适合高速光通信/脉冲测距
C. 反偏模式噪声更小
D. 光伏模式适合高速场景

**答案**：B
**解析**：零偏光伏模式无暗电流偏置项、1/f 噪声小，是光功率计、照度检测首选；反偏加宽耗尽区、结电容减小、载流子渡越快，带宽大幅提高，是激光脉冲接收（TOF 测距、光通信）的标配，代价是暗电流与散粒噪声增大。**跨阻放大器（TIA）是两种模式的前端标配，其反馈电阻决定增益带宽积的权衡——回答出 TIA 是面试加分点。**
**知识点**：光学-光电探测

### I-010 ★★
激光 TOF（飞行时间）测距中，测量 10 米距离的光往返时间是（光速约 3×10⁸ m/s）：
A. 约 33 ns
B. 约 67 ns
C. 约 33 ms
D. 约 6.7 ns

**答案**：B
**解析**：往返 20m ÷ 3×10⁸ m/s ≈ 67ns。**关键工程推论**：1ns 对应 15cm 距离，皮秒级计时误差就是厘米级测距误差——所以直接 TOF 用 TDC（时间数字转换器）而不用普通定时器；这也解释了相位法测距（测连续波相位差，把时间测量转成相位测量）在近距高精度场景的地位。A 忘了往返；C 差六个数量级；D 只算了单程的 1 米。
**知识点**：光学-TOF 测距

### I-011 ★★
光电传感器在户外强日光环境下误动作，有效的对策是：
A. 提高发射功率
B. 采用调制光+带通滤波解调（如 38kHz 调制），只响应自己发射的调制频率，抑制直流与低频背景光
C. 降低接收灵敏度
D. 更换更亮的 LED

**答案**：B
**解析**：日光在探测器的响应是缓变直流+低频分量，把发射光调制到特定载频（红外遥控的 38kHz、激光 TOF 的 MHz 级脉冲），接收链路只对载频带通解调，背景光与 50Hz 灯光闪烁被滤除。这是**所有抗强光光电产品的标准设计**（含自适应阈值背景光补偿）。A/C 治标不治本且降低信噪比裕量；D 方向错误。
**知识点**：光学-抗背景光

### I-012 ★★★
激光束的“发散角”对测距产品的影响，正确的说法是：
A. 无影响
B. 发散角决定远距离光斑尺寸与回波功率密度：远距时光斑增大，照射到目标后返回被接收口径收集的功率按平方衰减，直接影响最大量程
C. 发散角越小越好，无任何代价
D. 发散角只影响视觉美观

**答案**：B
**解析**：远场光斑直径 ≈ 距离 × 发散角（mrad 数值上≈每公里米数）。发散角大→远距光斑巨大→目标上的功率密度低→回波弱→量程缩水；发散角过小→**机械公差与目标表面不平整时“瞄不准”**，光斑可能完全错开角反射器，且人眼安全功率密度受限。实际产品是权衡：发散角常取零点几到几个 mrad。**链接测距链路预算：发射功率→光纤/透镜损耗→传输发散→目标反射率→回波→接收口径→探测器灵敏度，逐项 dB 相加就是系统设计师的基本功。**
**知识点**：光学-发散角与链路预算

### I-013 ★★
阅读原理图时，软件工程师应重点确认的信息包括（多选）：
A. MCU 引脚复用：某个 UART/SPI 实际接到哪个引脚、是否与其他功能冲突
B. 复位电路：上电复位时间常数、复位引脚是否有外部看门狗/按钮
C. 电源域：哪些外设是 1.8V/3.3V/5V，IO 电平是否匹配
D. 未使用引脚的处理（悬空/接地/内部上下拉配置）

**答案**：A、B、C、D
**解析**：这是“与硬件团队协作”（JD 任职资格）的实务清单：A 决定 pinmux 配置；B 解释“上电偶发不复位”（复位时间太短，电源未稳就放开复位——经典量产事故）；C 决定 IO 配置与电平转换；D 影响功耗与 EMC（悬空输入脚漂移引发漏电流与干扰）。**“看不懂原理图的嵌入式工程师遇到硬件问题只能干瞪眼”——这四项是最低门槛。**
**知识点**：硬件-原理图协作

### I-014 ★★
用示波器测量开关电源纹波的正确做法包括（多选）：
A. 探头用 ×1 或专用小环地线（弹簧地），避免长地线引线电感造成振铃假象
B. 带宽限制打开（20MHz），按规范测纹波有效值
C. 探头地线缠绕在探头上以减小环路
D. 触发到负载电流突变时刻，观察负载瞬态响应

**答案**：A、B、D
**解析**：A 对——鳄鱼夹长地线与探头尖构成环路天线，会耦合开关噪声，弹簧地/接地环是纹波测量标配；B 对——纹波指标按 20MHz 带宽限制定义（与电源认证规范一致）；D 是动态调试的正确姿势。C 表述有误导：地线“缠绕”并不能消除环路面积，正确做法是换短弹簧地（C 属于似是而非的干扰项）。
**知识点**：硬件-电源纹波测量

### I-015 ★★★
光电产品“测距数据偶发跳变”的排查方向包括（多选）：
A. 光学：镜头/窗口片污染、结露、光轴偏移、目标表面镜面反射
B. 电气：接收链路噪声（电源纹波耦合进 TIA）、地弹、探测器暗电流温漂
C. 算法：检波阈值过紧、多径回波选峰错误、滤波器未剔除离群值
D. 环境：强背景光、多台设备同频串扰、雨雪粉尘散射

**答案**：A、B、C、D
**解析**：这是 JD“光电调试”场景题的完整思维导图——四象限排查法。经验顺序：先看跳变分布（离散大跳变→多径/串扰；随温度漂移→温漂/暗电流；下雨天才出现→窗口污染散射）；再看原始波形（模块产测协议里必须有“读原始回波波形”的调试指令，见 H-032）；最后才动算法阈值。**“先物理后算法”是光电调试第一原则——阈值掩盖不了脏光路。**
**知识点**：光学-光电调试方法论

### I-016 ★★
常见的板级 ESD/浪涌/EMI 防护与抑制器件包括（多选）：
A. TVS 二极管（瞬态电压抑制）
B. 共模电感/磁珠（抑制共模噪声与高频干扰）
C. 压敏电阻（MOV，浪涌钳位）
D. 普通电阻分压网络

**答案**：A、B、C
**解析**：A 用于接口 ESD（USB/485 线上的 PS protection）；B 滤共模干扰（CAN/网口差分对上常见共模电感，磁珠串联在电源/时钟线上吸收高频）；C 用于交流电源口浪涌。D 是信号调理不是防护器件。**软件工程师的相关知识点**：EMC 试验（如 EFT 电快速瞬变脉冲群）打在接口上时程序跑飞/复位——软件侧要配合看门狗+关键数据 CRC+掉电安全存储（衔接模块 B-055），硬件侧要 TVS+滤波。软硬结合答才是满分。
**知识点**：硬件-防护器件

## 三、填空题（3 题）

### I-017 ★
I2C 上拉电阻的常见取值范围是 ______ kΩ；阻值过大导致 ______ 变慢，阻值过小导致 ______ 增大。

**答案**：2.2~10（典型 4.7）；上升沿（波形圆角，可能不满足时序）；总线电流（功耗、低电平驱动能力不足）
**解析**：与总线电容、电压、速度档相关：400kHz、3.3V 时 2.2k~4.7k 常见。上限受 RC 时间常数约束（t = −RC·ln(0.7)，上升沿要在时钟低/高期允许时间内到阈值）；下限受"开漏驱动器件灌电流能力"限制（要保证 VOL 电压）。示波器上看到 I2C 上升沿呈 RC 充电曲线就是上拉电阻的物理签名。
**知识点**：硬件-I2C 电气

### I-018 ★★
示波器带宽 rule of thumb：若被测信号为 100MHz 方波（含高次谐波），示波器带宽至少取基频的 ______ 倍（约 ______ MHz）才能较真实还原边沿。

**答案**：5；500
**解析**：经典经验法则 BW ≈ 5× 基频（或 0.35/上升时间估算带宽：350MHz 带宽对应 1ns 上升时间）。带宽不足的表观症状：方波变“正弦化”、边沿变缓、幅度偏低——**测到的不是信号的真实样子，而是示波器的低通滤波结果**。反过来讲：测晶振/高速时钟时，"看起来还行"的圆滑波形可能正是带宽不足的产物。
**知识点**：硬件-示波器-带宽

### I-019 ★★
激光安全等级中，Class 1 表示 ______；Class 3B/4 产品必须配备 ______ 与钥匙开关等工程控制。

**答案**：在正常（含合理可预见误用）条件下安全（“人眼安全”等级，如 CD/激光测距仪多为 1 类或 1M 类）；安全联锁
**解析**：IEC 60825 分级依据是可达发射限值（AEL）：1 类免管控；1M 类光学仪器观察受限；2 类靠眨眼反射（<1mW 可见光）；3R/3B/4 逐级危险。测距产品常用 905nm 近红外（人眼不敏感但可经晶状体聚焦伤视网膜），其 1 类 AEL 限额随脉冲宽度与重频变化——**发射功率上限往往由眼安全限制而非器件能力决定**，这是光电产品的合规红线，软件还要负责"脉冲重频限制"防止故障态超限。
**知识点**：光学-激光安全

## 四、判断题（3 题）

### I-020 ★★
MCU 未使用的 GPIO 引脚最好配置为模拟输入或带上拉的输入，而不是悬空。（ ）

**答案**：正确
**解析**：悬空输入脚的电平漂移在阈值附近反复翻转，引发：①输入缓冲器贯通电流（功耗增加）；②对外界噪声敏感，可能触发不期望的中断；③EMI 辐射加剧。推荐处理：无外部连接时配置为模拟输入（最省电）或输出固定电平；若硬件已外部上下拉则配置对应方向。很多“整机功耗莫名偏高几毫安”就是未用脚悬空漂移导致的。
**知识点**：硬件-未用引脚处理

### I-021 ★★
光电二极管的“暗电流”随温度升高而增大，是高温环境测距噪声增大的原因之一。（ ）

**答案**：正确
**解析**：暗电流由少数载流子热产生，温度每升高约 6~10°C 翻倍（器件相关）。它叠加在信号上成为散粒噪声底，直接抬高最小可检波功率——高温下信噪比恶化、量程缩水、数据抖动变大。工程对策：①温漂标定（不同温度的检波阈值/偏置补偿表，产测时标定写入，见 H-039 校准闭环）；②周期性遮光测暗电流做背景扣除；③硬件选 APD 温控或低暗电流器件。**“温度一高数据就飘”的光电产品问题，第一嫌疑人就是暗电流温漂。**
**知识点**：光学-暗电流温漂

### I-022 ★★★
激光相位法测距的精度由调制频率决定：频率越高，同一相位误差对应的距离误差越小，但量程受限于波长的非模糊范围。（ ）

**答案**：正确
**解析**：相位法测相位差 φ ∈ [0, 2π)，对应距离的非模糊范围 = c/(2f)。f=10MHz 时一个周期 15m；若真实距离 20m，测得相位与 5m 相同——**距离模糊**。因此相位法测距仪普遍采用多频组合：低频（如 150kHz，量程 1000m）定粗值，高频（如 10MHz/150MHz）精测，逐级精化。这是“精度与量程矛盾”的教科书案例，也是面试光电岗位的高频深度题。
**知识点**：光学-相位法测距

### I-024 ★★
简述用逻辑分析仪调试 SPI 通信不工作的标准流程。

**参考答案**：
1. **接探头**：CLK/MOSI/MISO/CS 四通道，共地，注意逻辑分析仪输入耐压（1.8V 档设对阈值）；
2. **设置采样率**：≥ 时钟频率 4 倍以上（采 10MHz SPI 至少 100MS/s）；

4. **触发**：触发 CS 下降沿，单次捕获一次完整传输；
5. **分析三要素**：①CS 是否在整帧期间有效（有的器件要求帧间拉高）；②时钟个数与预期字节数是否一致；③MOSI 上的命令字节是否正确、MISO 有无响应（全 0 或全 FF 分别指向“从机未驱动”与“线路断开/未上电”）；
6. **与示波器联动**：解码对了但设备不响应→换示波器看电气质量（幅值、上升沿、干扰）。
**知识点**：硬件-SPI 调试流程

### I-025 ★★★
什么是光电探测链路的“信噪比预算”？以脉冲激光测距为例说明。

**参考答案**：
以回波接收链路逐级记账：
1. **信号**：发射峰值功率 P0 → 光学发射效率 → 传输发散损耗（随距离平方衰减）→ 目标反射率 × 立体角 → 接收口径面积 → 探测器响应度（A/W）→ TIA 增益 → 信号幅度 S；
2. **噪声**：探测器暗电流散粒噪声 + 背景光散粒噪声（正比于背景光功率）+ TIA 热噪声 + 后级放大器噪声 → 折算为等效输入噪声 N；
3. **SNR = S/N**：可靠检波要求 SNR 达到检测概率与虚警概率指标（如 SNR≥6 对应较高检测概率）；
4. **推论**：最大量程 = SNR 恰好达标的距离；背景光增强、温度升高（暗电流）、镜头脏污（透过率降）都会压缩量程——把 I-015 的四象限排查量化成 dB 记账。
5. **软件相关**：知道噪声是高斯的，才能设计 CFAR 恒虚警检波阈值与 N 次平均降噪（平均 N 次提升 SNR √N 倍）。
**知识点**：光学-链路预算

### I-026 ★★
测距产品要做温度补偿标定，请设计标定流程（软硬件配合）。

**参考答案**：
1. **理论建模**：确定漂移源（暗电流、激光功率温漂、探测器延迟温漂、晶振频偏），建立补偿模型（如一次/二次多项式：偏置 = a·T² + b·T + c）；
2. **产测标定**：高低温箱内分温度点（如 -10/5/20/40/60°C）测标准距离，记录各点“实测−真值”偏差；
3. **拟合**：上位机（H-039 引擎）拟合系数 a/b/c，通过产测协议 CAL_WRITE 写入设备 Flash（先写后回读验证）；
4. **运行时补偿**：固件读板载温度传感器，查表/多项式实时修正测距结果；
5. **复测闭环**：补偿后再扫温度点验证残差达标（如 ±2mm）；
6. **注意**：标定用温度传感器与激光器需热耦合（读数代表结温），否则补偿错位；Flash 参数带 CRC 与版本号（衔接 B-055 掉电安全）。
**知识点**：光学-温漂标定

## 六、编程题（2 题）

### I-027 ★★
实现一个软件消抖的按键读取（含按下/释放事件与长按检测），适配裸机主循环调用。

```c
#include <stdint.h>

#define DEBOUNCE_MS   20      /* 消抖窗口 */
#define LONGPRESS_MS  1000    /* 长按阈值 */

typedef enum { KEY_IDLE, KEY_PRESSED, KEY_LONG } key_state_t;

typedef struct {
    key_state_t st;
    uint8_t     stable_level;    /* 稳定电平（1=按下，低有效取反后） */
    uint32_t    last_change_ms;  /* 电平变化时刻 */
    uint32_t    press_ms;        /* 按下时刻 */
    uint8_t     (*read_raw)(void);   /* 硬件层：读原始电平（已取反，按下=1） */
    void (*on_event)(int evt);       /* 回调：1=短按 2=长按 3=释放 */
} key_t;

/* 每 5~10ms 调用一次 */
void key_scan(key_t *k, uint32_t now_ms)
{
    uint8_t raw = k->read_raw();

    if (raw != k->stable_level) {
        /* 电平与稳定值不同：等消抖窗口确认 */
        if (k->last_change_ms == 0) k->last_change_ms = now_ms;   /* 记录首变时刻 */
        if (now_ms - k->last_change_ms >= DEBOUNCE_MS) {
            k->stable_level = raw;              /* 确认新电平 */
            k->last_change_ms = 0;
            if (raw) {                          /* 确认按下 */
                k->st = KEY_PRESSED; k->press_ms = now_ms;
            } else {                            /* 确认释放 */
                if (k->st == KEY_PRESSED)       /* 未触发过长按 → 短按事件 */
                    k->on_event(1);
                k->st = KEY_IDLE;
                k->on_event(3);
            }
        }
    } else {
        k->last_change_ms = 0;                  /* 电平回弹：重来 */
        if (k->st == KEY_PRESSED &&
            now_ms - k->press_ms >= LONGPRESS_MS) {
            k->st = KEY_LONG;
            k->on_event(2);                     /* 长按事件（可重复触发） */
        }
    }
}
```

**讲解**：核心思想：**用时间窗确认电平变化，而不是边沿中断里 delay 消抖**（delay 阻塞且中断里不该延时）。状态机区分 IDLE/PRESSED/LONG 三态：短按在“释放时”才判定（排除了长按），长按在“持续超时”时即时触发（用户不必松手）。这套结构可直接嵌进模块 B-054 的事件驱动主循环（按键扫描作为 10ms 周期任务）。**追问点**：为什么中断+延时消抖不好？——中断里 delay 20ms 会拖垮实时性，且无法处理长按分级。
**知识点**：硬件-按键消抖

### I-028 ★★★
实现一个简易 CFAR 式回波检波：从 ADC 采样数组中找激光回波脉冲位置，要求自适应噪声底，抑制虚警（对应 I-025 的算法落地）。

```c
#include <stdint.h>

/* 输入：样本数组 samples，长度 n
 * 输出：回波位置（索引），找不到返回 -1，噪声底通过 *noise_floor 带出
 * 原理：前段样本估计噪声底均值/方差 → 阈值 = 均值 + k·σ → 找超阈值的峰 */
int detect_echo(const uint16_t *samples, int n, int guard, int train,
                float k, float *noise_floor)
{
    /* 1. 用最前面 guard+train 个样本估计噪声（假设回波不在开头） */
    int n_est = guard + train;
    if (n_est > n / 2) return -1;             /* 参数不合理 */

    double sum = 0, sum2 = 0;
    for (int i = 0; i < n_est; i++) {
        sum  += samples[i];
        sum2 += (double)samples[i] * samples[i];
    }
    double mean = sum / n_est;
    double var  = sum2 / n_est - mean * mean;
    double sigma = (var > 0) ? __builtin_sqrt(var) : 1.0;
    uint16_t thr = (uint16_t)(mean + k * sigma);   // k 常取 5~8
    *noise_floor = (float)mean;

    /* 2. 扫描回波：跳过 guard 区，寻找超阈值后的局部峰值 */
    int best = -1; uint16_t best_val = thr;
    for (int i = n_est; i < n; i++) {
        if (samples[i] > thr) {
            /* 找该事件内的最大值（峰），提升 TOF 定时精度 */
            int j = i;
            while (j + 1 < n && samples[j + 1] > samples[j]) j++;
            if (samples[j] > best_val) { best_val = samples[j]; best = j; }
            i = j;                             /* 跳过本次事件 */
        }
    }
    return best;
}
```

**讲解**：这是**雷达/激光测距检波的经典思路（CA-CFAR 简化版）**：①自适应阈值——用噪声样本的统计量（均值+k·标准差）代替固定阈值，背景光/温度变化时（I-021）虚警率保持恒定，这正是 CFAR（恒虚警率）的含义；②训练单元/保护单元的概念——保护单元紧邻待测单元防止信号泄漏进噪声估计（本例简化为首段估计）；③取峰而非取沿——峰值点对应脉冲中心，配合插值（抛物线插值三点定峰）可达到亚采样精度，直接提升 TOF 分辨率。**追问链**：k 怎么选（检测概率 vs 虚警率的权衡）？多目标怎么办（找多个峰+第二回波窗口）？噪声非高斯时？（直方图类 OS-CFAR）——答出这些就是光电算法岗水准。
**知识点**：光学-检波算法

### I-030 ★★★
**硬件工程师说“板子没问题，是软件问题”，你如何用系统化方法界定软硬件责任边界？**

**参考答案**（展示方法论，不背教条）：

**1. 先固定证据，不猜**
- 复现路径固化（最短复现步骤、概率、与温度/时间相关性）；
- 用示波器/逻辑分析仪在故障发生时抓关键总线与控制信号（I-024 流程），把“软件以为发了什么”与“线上实际是什么”对齐。

**2. 分层切割定位**
- **纯软件层**：日志、状态机轨迹、断言；换个固件版本对比；
- **软硬边界层**：MCU 引脚输出 vs 器件输入引脚（同一信号两端测）——MCU 脚上有、器件脚上没有 → PCB 断线/虚焊；两端都有但器件不响应 → 时序参数或器件问题；MCU 脚上就没有 → 软件问题；
- **电源/复位层**：故障时同步监测电源轨（触发到异常信号，滚动模式）——掉电压尖峰、复位脚毛刺都能现形（I-006 单次触发）。

**3. 交叉实验**
- 换板/换器件/换固件三维置换：同板换固件复现→软件嫌疑；同固件换板复现→硬件嫌疑；只有特定组合复现→交互问题（如软件配置与某批次器件参数边界）；
- 统计：5 块板 3 块复现与 1 块板 100% 复现，指向完全不同。

**4. 常见“板子没问题但确实是硬件锅”清单**（体现经验）
- 上电时序临界（复位释放太早，偶发启动失败）；
- 未用脚悬空、地弹、参考地选择错误导致测量误判；
- 器件批次差异落在软件时序裕量之外。

**5. 输出与协作**
- 每轮实验留证据（波形截图+日志编号），结论附数据；
- 提出可验证的下一步假设（“若是复位毛刺，示波器单次触发应能抓到”——可证伪）。
**评分要点**：证据意识 / 两端测量法 / 置换实验设计 / 可证伪假设 / 协作姿态（对事不对人）。
