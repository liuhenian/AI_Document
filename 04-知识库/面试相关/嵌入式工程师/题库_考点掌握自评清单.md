# 嵌入式软件工程师 · 考点掌握自评清单

> **使用方法**：
> 1. 对照每条考点，诚实标注：✅ 已掌握（能给别人讲清楚）/ 🟡 模糊（看过但讲不透）/ ❌ 未掌握；
> 2. 🟡 和 ❌ 的考点回到对应模块重学对应题目；
> 3. 全部 ✅ 后，用「面试题文件」做模拟面试：遮住参考回答，口述作答并录音回听；
> 4. 建议每 2 周复评一次，直到面试前全部 ✅。

## 模块 A：C 语言与编程规范（70 题）

- [ ] volatile 的三个适用场景与编译器优化原理（A-001~003）
- [ ] static 在函数内/文件内/修饰函数的三种语义
- [ ] const 修饰指针的读法（右往左）与 const 数据放在哪个段
- [ ] 内存布局五区：.text/.rodata/.data/.bss/堆/栈，谁能读写谁占用 Flash
- [ ] 内存对齐规则手算（含 #pragma pack、位域对齐）
- [ ] 大小端检测的两种方法（union/指针强转）
- [ ] 位操作四件套：置位/清零/取反/测试，不破坏其他位
- [ ] 函数式宏的两大陷阱（副作用参数重复求值、优先级），inline 替代
- [ ] 有符号/无符号混合比较与回绕（size_t 循环倒序陷阱）
- [ ] strncpy/strlcat/memcpy 安全用法与越界场景
- [ ] 栈溢出的原因与预防；内存泄漏三防线
- [ ] 设计：固定块内存池、表驱动状态机、协议帧格式设计（A-068~070）
