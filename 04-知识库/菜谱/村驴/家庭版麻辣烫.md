## 一、基本信息

- **份量**：一口小锅，**2 人份**（三碗水 + 一袋牛奶）
- **总耗时**：约 30 分钟
- **主火候**：**牛油炒化 → 最小火炒豆瓣酱 → 大火烧开 → 最小火咕嘟 2 分钟 → 大火煮料 → 关火淋酱**
- **成败就靠这一件事**：**芝麻酱要"少量多次加水"，调到"酸奶状"**。视频原话"**因为我们用的芝麻酱浓稠度不同，所以这个水它没有固定用量**"。
- **这道菜的两个"神秘调料"**（视频开头说的）：
  1. **牛奶**——代替店里用的"植脂末"，**让汤变白变厚，还不腻**
  2. **红腐乳汁**——"**吃不出火锅味，只会给这个麻辣烫增香**"

## 二、买什么

### 麻酱（灵魂）

| 食材 | 用量 | 备注 |
|---|---|---|
| **二八酱**（芝麻花生混合酱） | **满满 2 大勺** | **不要纯芝麻酱，也不要纯花生酱** |
| **白糖** | **1 勺** | **用量就是需要这么多，少了出不来那个味儿** |
| **味精** | **1/3 勺** | — |
| **生抽** | **2 勺** | — |
| **蚝油** | **半勺** | — |
| **花椒油** | **半勺** | — |
| **清水** | **少量多次**，调到**酸奶状** | 不固定，看麻酱浓稠度 |

### 蒜水

| 食材 | 用量 |
|---|---|
| **大蒜** | **4 粒**，挤碎 |
| **清水** | **3 勺** |

### 汤底

| 食材 | 用量 | 备注 |
|---|---|---|
| **火锅底料**（小四方块） | **半块** | 牛油的 |
| **郫县豆瓣酱** | **1/3 勺** | — |
| **清水** | **3 碗**（吃米饭的小碗） | — |
| **牛奶** | **1 袋 240 ml** | 代替植脂末 |

### 涮料（按耐煮程度分批）

| 食材 | 备注 |
|---|---|
| **粉条** | **提前开水烫软**。**别用龙口粉丝，太细** |
| **黄面条 / 冷面**（可选） | 也要**提前浸泡** |
| **火锅丸子** | **不爱熟，最先下** |
| **久煮的青菜**（如白菜帮、土豆片） | 最先下 |
| **方便面饼**（见 **图 13**）| 和丸子一起下 |
| **易熟青菜**（如生菜、菠菜） | **最后下** |
| **油条** | **一定要最后放**，不然煮烂 |

### 收尾

| 食材 | 用量 |
|---|---|
| **孜然** | **1/3 勺** |
| **红腐乳汁** | **2 勺** |
| **醋** | 吃之前按口味加 |
| **辣椒油** | 按口味加 |

> **为什么用"二八酱"**：视频原话"**单独使用芝麻酱容易发苦，单独用花生酱又不够香**"。**二八酱＝20% 芝麻酱 + 80% 花生酱**（也有 2:8 的其他配比），**香而不苦**。
> **粉条不要用龙口粉丝**：视频原话"**那个太细了**"。**细粉丝一煮就烂，捞不起来**。**要粗一点的粉条（红薯粉条、土豆粉条）**。

## 三、备菜

### 1. 泡粉条、泡面（10 分钟，最先做）

**粉条提前用开水烫上，烫软**。见 **图 1**

**如果要放黄面条或冷面，也要提前浸泡**。

> 视频原话"**这些面非常的吸水，下锅之后会把汤里煮干**"。**不提前泡透，面会把汤吸干，最后变成一锅干拌**。

### 2. 调麻酱（5 分钟，**全篇最关键**）

碗里放：

1. **二八酱满满 2 大勺**。见 **图 2**
2. **白糖 1 勺**。见 **图 3**
3. **味精 1/3 勺**
4. **生抽 2 勺**
5. **蚝油 半勺**
6. **花椒油 半勺**

**然后"少量多次加水"，一边加一边搅，调到"酸奶状"**。见 **图 4**

> **判据是"酸奶状"，不是"多少水"**：视频原话"**因为我们用的芝麻酱浓稠度不同，所以这个水它没有固定用量**"。
> **"少量多次"是技术要点**：**一次倒一大杯水，麻酱会"离水"结块，怎么搅都澥不开**。**一小勺一小勺加，每加一次搅到完全吸收再加下一次**。
> **"酸奶状"长什么样**：**舀起来能缓缓流下、落下时叠成一个小堆，不会立刻摊平**。太稠挂不住料，太稀变成汤。

### 3. 做蒜水（2 分钟）

**4 粒大蒜挤碎，加 3 勺清水，搅拌均匀就是大蒜水**。见 **图 5**

> 视频原话"**只要你不排斥大蒜，这个就一定要放**"。**蒜水比蒜末更均匀**——**它挂在每一根粉条上，而不是集中在几口**。

## 四、做法（先熬汤，再分批下料）

| 步 | 火候 | 锅里什么样 | 做什么 | 判据 |
|---|---|---|---|---|
| 1 | — | — | 小锅（什么锅都行），**少来点油** | — |
| 2 | 中火 | 油热 | **下半块火锅底料** | 见 **图 6** |
| 3 | 中火 | **牛油炒融化** | **转最小火** | 块底下一摊红油、块体软塌还没起烟，这时马上转最小火 |
| 4 | **最小火** | 红油慢慢出来 | **下 1/3 勺郫县豆瓣酱**，**彻底炒香炒透** | 见 **图 7** |
| 5 | 最小火 | 香味浓、油色深红 | **加 3 碗清水（吃米饭的小碗）** | 见 **图 8** |
| 6 | — | — | **倒入一袋牛奶（240 ml）** | 见 **图 9** |
| 7 | **大火烧开 → 转最小火** | 汤在微微翻 | **咕嘟 2 分钟** | 见 **图 10** |
| 8 | 最小火 | 汤面浮着八角、辣椒段、花椒粒，捞完汤色发匀、只剩细油花 | **把里面的料渣打捞干净** | 见 **图 11** |
| 9 | 大火 | 丸子、面饼一下去汤面被压平、锅边重新翻起泡 | **下火锅丸子 + 久煮的青菜 + 方便面饼** | 见 **图 12、图 13** |
| 10 | 大火 | 汤在滚 | **煮熟** | 丸子浮起、面散开 |
| 11 | 大火 | 粉条一进去就软塌、青菜压在汤面打转，液面被顶高 | **加泡好的粉条 + 易熟的青菜** | 见 **图 14** |
| 12 | 大火 | **青菜烫软** | **就是好了** | 叶子由挺变塌、颜色转深，梗还能掐断就该关火 |
| 13 | — | — | **淋入调好的麻酱** | 见 **图 15** |
| 14 | — | — | **倒入蒜水** | — |
| 15 | — | — | **孜然 1/3 勺 + 红腐乳汁 2 勺** | 见 **图 16** |
| 16 | — | — | **关火。吃之前按口味加醋、辣椒油** | 见 **图 17** |

> **第 4 步"炒透豆瓣酱"是很多人做不好麻辣烫的原因**：视频原话"**很多人不喜欢郫县豆瓣酱的味道，是因为你没有把它炒透**"。
> **生豆瓣酱有一股"生酱味"和"闷味"**，只有**小火慢炒到红油析出、酱体发亮**，那股味道才会变成"香"。**中大火炒，外面糊了里面还是生的**。
> **第 7 步"咕嘟 2 分钟"不能省**：视频原话"**要不然火锅底料里面的香味它出不来**"。**火锅底料是"压缩的香味"，需要时间在汤里化开**。**烧开就下料，汤是"清水加辣"**。
> **第 8 步"捞料渣"是为了口感**：**火锅底料里有八角、桂皮、辣椒段、花椒粒**，**留在汤里会越煮越苦、越煮越麻**，吃的时候还硌牙。**捞干净，汤才"厚而不杂"**。
> **第 9–12 步"分批下"是麻辣烫的基本功**：**耐煮的先下、易熟的后下**。**一起下锅，丸子还没熟青菜已经烂了**。
> **第 13–15 步"麻酱、蒜水、孜然、腐乳汁"是"关火后"放的**：**这四样都是"香"不是"煮"**。**下了锅再煮，麻酱会澥、蒜香会跑、孜然会苦**。

## 五、调味（四组，别搞混）

| 组 | 放什么 | 用量 | 什么时候放 | 少放会怎样 | 多放会怎样 |
|---|---|---|---|---|---|
| **① 麻酱** | 二八酱 | **满满 2 大勺** | 提前调好，最后淋 | 汤不挂，喝着水塌塌 | 糊嘴，把汤底的辣盖住 |
| | 白糖 | **1 勺** | | 咸鲜发尖，不回甘 | 甜得发腻，麻酱变甜酱 |
| | 味精 | **1/3 勺** | | 鲜味薄，回口短 | 口干，鲜得发假 |
| | 生抽 | **2 勺** | | 咸鲜不够，麻酱发淡 | 死咸，把芝麻香盖掉 |
| | 蚝油 | **半勺** | | 鲜味薄，酱挂不住菜 | 发黏发咸，颜色发闷 |
| | 花椒油 | **半勺** | | 少一层麻香，麻酱发平 | 麻得发苦，舌头木 |
| | 清水 | **少量多次，到酸奶状** | | 麻酱太稠，拌不开、坨成块 | 太稀，挂不住菜、碗底一层水 |
| **② 蒜水** | 大蒜 | **4 粒** | 最后倒 | 压不住麻酱的腻，吃半碗就闷 | 蒜冲，抢掉汤底香 |
| | 清水 | **3 勺** | | 蒜水太冲、发辣 | 蒜味被冲淡，等于白放 |
| **③ 汤底** | 火锅底料 | **半块** | 先炒 | 汤底不红不香，只剩奶味 | 辣冲、油厚，齁得喝不下汤 |
| | 郫县豆瓣酱 | **1/3 勺** | 最小火炒透 | 红油出不来，汤色发白 | 咸辣压过奶香，汤发苦 |
| | 清水 | **3 碗** | | 汤太浓，煮到后面发咸发糊 | 汤味被冲淡，得回头补底料 |
| | 牛奶 | **240 ml** | | 汤不白不醇，辣得发直 | 奶味盖住辣香，像喝奶汤 |
| **④ 收尾** | 孜然 | **1/3 勺** | 关火前撒 | 少一层烧烤气，收尾发平 | 孜然抢味，像在吃烤串 |
| | 红腐乳汁 | **2 勺** | 关火前加 | 少一层发酵的咸鲜，汤发平 | 腐乳味冲，汤发酸 |
| | 醋 / 辣椒油 | 按口味 | 吃之前 | 不解腻、不够辣，吃着闷 | 酸辣盖住麻酱和奶香 |

> **为什么加牛奶**：视频原话"**正常麻辣烫或者烤鱼想要好吃，是需要往里头加一些植脂末的，但是这个东西大家都不喜欢，所以咱们用牛奶来代替**"。
> **牛奶的作用和植脂末一样**：**乳脂和乳蛋白把辣味"包"起来，让汤变白变厚、辣而不燥**。**还多了钙和蛋白质**。
> **糖 1 勺在麻酱里"不能少"**：视频原话"**糖的用量就是需要这么多，少了出不来那个味儿**"。**它不是为了甜，是为了"合"——把麻酱的涩、生抽的咸、花椒油的麻拢在一起**。

## 六、别翻车

1. **用纯芝麻酱** → 发苦 → **二八酱**
2. **用纯花生酱** → 不够香 → **二八酱**
3. **麻酱一次加一大杯水** → 结块、澥不开 → **少量多次**
4. **麻酱调太稠** → 挂不住、糊嘴 → **酸奶状**
5. **麻酱调太稀** → 变成汤、没味 → **酸奶状**
6. **糖省了** → 味道"立不起来" → **1 勺不能少**
7. **粉条用龙口粉丝** → 一煮就烂 → **粗粉条**
8. **粉条不提前泡** → 吸干汤 → **开水烫软**
9. **豆瓣酱不炒透** → 生酱味、闷味 → **最小火炒到油亮**
10. **豆瓣酱用中大火** → 糊、发苦 → **最小火**
11. **加牛奶后大火猛滚** → 起沫、溢锅、奶腥 → **烧开转最小火**
12. **不咕嘟就直接下料** → 底料香味出不来 → **2 分钟**
13. **不捞料渣** → 越煮越苦、硌牙 → **捞干净**
14. **所有料一起下** → 丸子没熟菜已烂 → **分批下**
15. **油条早放** → 煮成一坨面 → **最后放**
16. **麻酱下锅一起煮** → 澥掉、汤变浑 → **关火后淋**

## 七、孕期适配

- **麻辣烫在孕期是"可控性非常高"的一锅——因为所有东西都是你自己放的。关键不是"能不能吃"，是"放什么"**
- **先说这一版的两个加分项**：
  1. **用牛奶代替植脂末**——**这是这版最值得夸的地方**。**店里的麻辣烫为了"白、厚、香"，常加植脂末（奶精），含反式脂肪酸**。**牛奶完全没有这个问题，还多了钙（240 ml 牛奶约 240 mg 钙）和 8 g 蛋白**
  2. **自己控盐**——**店里的汤是"越煮越咸"，这一版盐的总量你能数清**
- **要改的三件事**：
  1. **火锅底料半块 + 豆瓣酱 1/3 勺 + 生抽 2 勺 + 蚝油半勺 + 腐乳汁 2 勺**——**这五样的盐加起来约 6–7 g（2 人份）**。**一人约 3–3.5 g**。**孕期一天上限 5 g 盐，一顿吃掉 3 g 是可以的，但当天其余两顿要极清淡**
     - **水肿、血压偏高：火锅底料减到 1/3 块，腐乳汁减到 1 勺，生抽减到 1 勺**
  2. **丸子要挑，或者换掉**——**火锅丸子是"加工肉制品"，主要成分是淀粉、大豆蛋白、磷酸盐、亚硝酸盐、香精**。**它本身不是"毒"，但对孕期来说"营养密度极低、钠极高"**
     - **更好的替代**：**鲜虾、鲜牛肉片、鸡胸肉片、鲜豆腐、鹌鹑蛋、虾滑（自己打的）**
     - **如果就爱吃丸子**：**买配料表第一位是"肉"的（不是"水"或"淀粉"）**，**煮到完全浮起、中心烫透**
  3. **别喝汤**——**这一锅的盐、油、嘌呤几乎全在汤里**。**吃料、喝一小口尝尝味就行**。**孕期不建议"把汤喝完"**
- **可以放心的地方**：
  - **全程大火滚煮**，**没有生食环节**（除了最后加的醋和辣椒油，那两样不构成风险）
  - **青菜煮到"烫软"就出锅**，**维生素 C 损失比久煮少**
  - **粉条、面条充分烫透**，**不存在"夹生"**
- **孕期实操建议**：
  1. **丸子换成鲜虾 + 牛肉片 + 豆腐**，蛋白质质量立刻上去
  2. **青菜多放**（易熟的那种最后下，烫软就吃）
  3. **麻酱保留**（它是钙和好脂肪的来源），**但糖减到半勺**
  4. **腐乳汁保留 1 勺**（它就是"香"的来源，减半后味道差别不大）
  5. **不喝汤，剩下的汤倒掉不要留**（**反复加热的辣汤，亚硝酸盐会升高**）
- **一句话**：**这一版麻辣烫的"底子"比店里干净得多——牛奶代替奶精、盐你能数清、菜自己洗。把丸子换成鲜肉鲜虾、汤别喝完，孕期吃一顿完全没问题**
- **这一份的账：钠 ≈ 2400–2800 mg（6–7 g 盐，2 人份），是孕期每日钠上限 2000 mg 的 120%–140%；按 2 人分，一人约 1200–1400 mg、60%–70%**

## 八、做完填一句

- 麻酱调到〔酸奶状／太稠／太稀〕，加水加了〔几次〕
- 豆瓣酱炒了〔多久〕，有没有〔生酱味／香味透〕
- 咕嘟了〔2〕分钟，料渣〔捞了／没捞〕
- 丸子用的〔火锅丸／鲜虾牛肉〕，汤〔喝了／没喝〕
- 整体咸度〔刚好／偏咸〕
