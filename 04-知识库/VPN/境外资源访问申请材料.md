## 一、申请背景与业务目的

APM 产品处于功能规划与竞品对标阶段，需要持续跟踪国内外同类产品的功能设计、指标口径、技术实现路径与定价策略。这类信息主要分布在厂商官网、产品文档站、技术博客与发布说明中，**没有国内镜像，也无法通过公开渠道转述获取**。

典型调研对象（按类别）：

| 类别 | 代表对象 |
|---|---|
| 商业 APM 厂商 | Datadog、New Relic、Dynatrace、Splunk、AppDynamics、Elastic |
| 可观测性开源项目 | Grafana Labs、Prometheus、OpenTelemetry、VictoriaMetrics、Jaeger |

| 技术社区与工程博客 | 各厂商 engineering blog、InfoQ、Hacker News |

调研内容以**产品文档、功能说明、指标定义、定价页、版本发布说明**为主，属于公开信息，不涉及任何内部或敏感数据。

## 二、当前访问受限的具体表现

在申请前已做实测，结论是：**当前出口策略对境外 443 端口默认放行，仅对少数目标存在拦截**。

测试样本 24 个境外目标，结果分布：

| 可达（14 个） | 不可达（10 个） |
|---|---|
| github.com、api.github.com | www.google.com |
| pypi.org、files.pythonhosted.org | www.youtube.com |
| registry.npmjs.org | www.wikipedia.org |
| cdn.jsdelivr.net | huggingface.co |
| www.microsoft.com（及更新服务） | 8.8.8.8、1.1.1.1 |
| www.bing.com、www.apple.com | 34.143.244.x（GCP 新加坡段） |
| www.amazon.com | 35.187.250.x（GCP 段） |
| Cloudflare 全段（104.16.x） | — |

**关键结论**：可达目标横跨 Azure、Fastly、Cloudflare、Akamai、Amazon 五个不同云厂商的自治域，说明出口策略并非域名白名单，而是**默认放行境外 HTTPS、对特定目标定向拦截**。

因此本次申请的性质是：**在现有默认放行策略上，补充允许调研所需的少数目标**，而非申请新建特殊通道。

## 三、国内替代方案的覆盖范围与缺口

| 需求类型 | 国内方案能否覆盖 | 说明 |
|---|---|---|
| 依赖包下载（pip / npm / docker / maven） | 可以 | 已配置清华、npmmirror 等镜像，速度优于直连 |
| 开源项目源码 | 可以 | Gitee 存在同步镜像 |
| 厂商官网产品页、功能说明 | **不可以** | 动态页面，无镜像，需实时访问 |
| 产品文档站、API 参考 | **不可以** | 多数为 JS 渲染，无静态快照 |
| 定价页、套餐对比 | **不可以** | 商业信息，无第三方转载 |
| 版本发布说明（changelog / release notes） | 部分 | GitHub 侧可达，官网侧不可达 |
| 技术博客、工程实践文章 | **不可以** | 无镜像渠道 |

**缺口集中在「产品与商业信息」这一层**，这部分正是调研的核心产出，也是国内渠道完全无法替代的部分。

## 六、建议的放行方式

按实施成本从低到高，供选择：

**方案 A（推荐）：域名白名单分级放行**
按类别建立域名清单（先提交首批约 30–50 个域名），审核后加入白名单。符合最小权限原则，边界清晰，后续按需增补。

**方案 B：分时段放行**
工作时段（如 9:00–19:00）放行境外 HTTPS，非工作时段维持现状。实现简单，风险窗口可控。

**方案 C：专用出口**
为研发网段单独分配一条出口线路，仅承载白名单流量。隔离性最好，但需要网络改造，成本最高。

**建议采用方案 A**，配合季度复核，既能满足业务需求，也便于安全团队掌握访问范围。

## 备注：为什么不建议使用个人渠道

作为技术评估的补充说明：曾考虑过自建代理或采购第三方通道，评估后确认不合适，主要原因有三：

1. **不可维护**：这类通道平均 1–2 个月失效一次，每次恢复需 20–40 分钟，年累计维护成本约 10 小时，且失效时无任何责任方
2. **不可控**：第三方服务商跑路、整条线路被查属于常见风险，无售后、无申诉渠道
3. **责任边界不清**：在公司内网主机上运行个人采购的跨境通道，一旦发生安全事件，责任归属将难以界定

相比之下，走正式流程虽然有一次性的材料与审批成本，但通过后**零维护、有责任主体、可审计**，长期看是成本最低的路径。
