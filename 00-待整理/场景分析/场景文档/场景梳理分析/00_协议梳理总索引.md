**分组关系（避免混淆，各篇 1.3 节均有边界判据）**
- **VLAN ↔ QinQ**：前者是单层标签与端口模型，后者是在其之外再加一层服务标签。QinQ 篇只处理「标签栈层级与映射」，单层 VLAN 的 PVID / 放行列表问题一律回 VLAN 篇。
- **VLAN ↔ ACL**：协议 VLAN 的匹配**走 ACL**、superVLAN 的匹配**走 SCL**，两条路径叠加是 `DS-L2-01` 最典型的冲突源；ACL 篇只处理匹配与编号机制本身。
- **STP ↔ RLDP**：STP 管稳态（选树与阻塞），RLDP 管突发（周期探测）；BRIDGE 模块**同时维护两者的端口状态**，「状态整合缺陷」是 `DS-L2-04` 的核心机理（行 575 类）。
- **QinQ ↔ 标签解析**：合为一篇，因为 `DS-L2-02` 的根因（outer/inner tag 误识别）本质是 QinQ 场景下的芯片解析问题，与 QinQ 共用同一套标签栈模型。
- **二层系列 ↔ 路由 PBR 篇**：两者都依赖 ACL 与 classid，但 PBR 的 classid 残留归 `DS-RT-07`/`08`，VLAN CLASS 的 classid 冲突归 `DS-L2-05`；ace 表项资源耗尽统一外归 `EXT-FWD`。

## 六、事实基线与纪律（写作时锁定）

- **禁止编造**：版本号、补丁号、品控 ID、具体 API 路径、Sheet8 行号一律不得杜撰。
- **命令纪律**：仅规范 3.2 已实证的命令可直接写，其余一律标「（待实机核对）」。
- **转发面命令口径**：RGOS 无 Cisco CEF 类命令，统一用 `show ip fib` / `show forwarding-table`（待实机核对）。
- **子场景 ID 白名单**：管理面仅 `DS-MGMT-01`~`09`，路由仅 `DS-RT-01`~`08`；不得自造编号。
