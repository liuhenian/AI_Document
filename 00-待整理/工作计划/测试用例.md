| 意图大类       | 编号    | 用户输入                                        | 说明                      |
| ---------- | ----- | ------------------------------------------- | ----------------------- |
| **简单查询**   | SQ-01 | “核心交换机01的当前CPU使用率”                          | 单设备单指标，无时间修饰            |
|            | SQ-02 | “10.104.136.111这台设备的内存使用情况”                 | 使用IP指定设备                |
|            | SQ-03 | “查看HundredGigabitEthernet1/0/1端口的丢包率，最近5分钟” | 指定端口和时间窗口               |

|            | CD-03 | “CPU高且内存使用率小于20%的设备”                        | 多指标组合条件                 |
| **关联查询**   | AQ-01 | “核心交换机A下联的所有接入交换机的丢包情况”                     | 拓扑下联查询                  |
|            | AQ-02 | “查询设备B上联端口的流量”                              | 上联关系查询                  |
|            | AQ-03 | “所有连接到核心交换机01的设备的CPU使用率”                    | 逆拓扑关联                   |
| **派生计算**   | DM-01 | “设备B的内存使用率”                                 | 内存使用率派生计算               |
|            | DM-02 | “查询设备C的FP资源容量使用百分比”                         | FP容量展开计算                |
|            | DM-03 | “核心交换机的全局丢包率（所有端口总和）”                       | 端口指标聚合派生                |

|            | EA-03 | “变更记录编号CHG001操作前后5分钟的丢包率”                   | 变更事件锚点                  |

|            | FR-03 | “IP是10.0.0.1的设备，那个流量最大的端口状态”                | 部分模糊（设备通过IP明确，但端口需排序发现） |
| **多问句并行**  | MI-01 | “设备A的CPU怎么样，B的丢包率高吗？”                       | 两个独立查询                  |
|            | MI-02 | “查一下核心交换机内存，再看汇聚交换机的温度”                     | 不同设备不同指标                |
|            | MI-03 | “丢包率最高的5个端口是哪些？核心交换机的总流量是多少？”               | 一个条件发现，一个简单查询           |
