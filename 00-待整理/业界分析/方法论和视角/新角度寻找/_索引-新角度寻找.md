## 二、四份方法论的核心结构速览

**04 新方向发现（现行主线·面向规划）**：Step 0 约束解析（F1–F4 → P1–P4 四参数，半天） → Step 1 困难归一（现象 → 五类**判断动作**，1 天） → Step 2 供给盘点四层（同赛道／邻赛道／跨赛道／标准，1 天） → Step 3 三通道合流（半天） → Step 4 三道筛（合法性／新颖性／可规划性，1 天） → Step 5 方向卡（七字段，1 天） → Step 6 方向组合（A/B/C 三档 + 触发条件，半天） → Step 7 链接核验（半天）＝ **≈5.5 人日**
> **三条不可让的判断**：①**只有 B 命中（有技术无人被坑）的方向直接否掉**；②数量必须乘**困难纯度**（M08 命中 53 条排第 3，纯度只有 37%，其中 33 条是等版本修复）；③按「**能否切出第一段**」排序，不按价值排序。
> **五类判断动作**（取代故障类型分组）：取值有效性／多源一致性／身份与语义／采集完整性／现场可复原。
> **第 0 条铁律**：**链接不通的证据不算证据**，每条外部证据都要写「核验方式 + 状态 + 日期」。

**01 内部调研**：L0 考核口径 → L1 事实核验 → L2 判断链 → L3 前提对照 → L4 收敛（4 周）
> 采样单元是**判断事件**（谁判、依据什么、结论可不可信、有没有被反驳），断点标签 D1–D6（缺结论/依据/复现/基线/归属/通道）。

**02 外部调研**：L1 需求 → L2 供给 → L3 采购 → L4 收敛（4 周）
> 采样单元是**客户场景**（客户原话、损失量、现在的土办法），卡点标签 K1–K5，必须过「标书加分项 + 渠道装得动」这两关。**当前挂起。**

**03 跨赛道（供给先行）**：核对 96 个问题术语（附录 A 已给中英对照 + 释义） → 扫三个货架 + 设备侧货架 → 填能力卡 → 反向匹配三问 → 三道闸门 → 半天验证（14 天）
> **第一动作不是想问题，是抄词**。理由：解法的数量有限（可枚举），问题的数量无限（不可枚举）；且问题的名字是解法的副产品，没看过解法就没有提问的词汇。判断被压到最后 3 天，且只做减法。
> 关键工具仍是**困难分类表**（附录 E.2）：按困难类型找技术，不按业务领域找。突破只来自三种变化——技术迁移、约束变化、边界变化。
